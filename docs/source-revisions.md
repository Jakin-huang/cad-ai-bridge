# 任务书换版与依赖失效

工程引擎1.12.0增加任务书来源换版。新任务不能直接沿用旧任务的用途解释、数值要求、模型、图纸或审核结论；旧来源及文件继续保留作历史记录。当前覆盖单一活动任务书的顺序换版，尚不支持任意多文档语义协调或建筑、供电参数的权威改值。

`replace_brief`接收jobId、requestId、expectedRevision、expectedInputSHA256、briefFile、expectedFileSHA256、sourceId、supersededSourceId和description。只读取允许根内的UTF-8文本，按原文件摘要核对；原始字节和去可选BOM后的文本分别冻结，换行不转换，两个摘要不能混用。来源注册表保留旧摘要及双向替代链，拒绝复用来源ID、无内容变化、非当前来源、越界文件、摘要变化和循环链。

换版删除引用已退役来源的要求，清除依赖的功能分类，撤销当前模型、物理复核、交付与审核。历史模型和文件不覆盖；测试审核必须继续标记simulation。已有缺项不清空，历史注记不能成为新任务的证据。实际CAD交付状态不明或计算持锁时禁止通过换版绕过恢复。

`status`使用`{action:"status",jobId,section:"source_changes"}`读取精确契约、当前来源、影响和待确认条件。`reconcile_brief`仍需requestId、expectedRevision、expectedInputSHA256和requirements，另可提交functionalIntake、carryForwards。要求项精确字段为id、rule、value、roomIds、sourceIds、rationale、status；规则及单位由契约提供，不使用kind、单数roomId等猜测字段。

新要求必须引用活动来源。功能只补未知主用途或未评估兼用用途，逐字引用当前任务书，既有独立来源的分类和要求不能覆盖。部分未决解释可逐次补充，已解决的解释不被后续补充覆盖；新任务在上一任务未补齐时到来，也会对全部退役祖先执行失效控制。

`carryForwards`逐项提交key、expectedValueSHA256、reason、evidence，evidence为sourceId与quote。它只确认未改动的冻结值，不能修改几何、电气、光学、产品或标准参数。每项需有本版原句，值摘要须一致。项目标识、范围与设计日期总需确认；其他条件按来源依赖确定。仍引用旧来源、条件未确认、需改值或标准失效时继续阻断；不能以“沿用”替代新建筑图或新标准。状态documented可保守变为interpreted，原有assumed不得升级，管理器另核对归档输入中的假设状态。

来源发布先写摘要绑定的事务日志，再发布唯一输入修订及派生状态。相同请求可继续未完成的文件发布；成功后重放返回当前状态，不把已交付状态倒退为prepared。后续修订已存在时旧请求拒绝。该控制器文件故障注入不等于真实CAD进程中断恢复验收。

独立检查核对来源链、退役引用、条件摘要和新图换版说明。报告及任务中心展示历史/当前来源、沿用原句和保留假设；CAD设计说明标出新旧任务身份及历史审核失效。当前sourceChange.status是本次资料登记的阶段快照，是否可设计、是否已出图以项目当前status及检查为准。

本机实测用例为已知8×6m合成办公/会议空间，在既有实际客户端R1上换版。旧任务500—700lx、U0≥0.6、LPD≤8及感应手动控制保留为历史；新任务要求总平均600—700lx、U0≥0.65、LPD≤6及区域集中手动。未改变几何、供电、产品、表面或站姿条件。首轮客户端经历1次契约错误后完成登记，但严格零错误验收失败；补精确字段发现后，第二来源版本复验零错误。两轮工程指标相同，仅来源标识变化；文件字节不同，不能称相同输入复跑。

最终R5真实CAD保存重开，12套/276W、1回路、5张A3，总平均621.50lx、U0约0.657、站姿参考UGR最大16.91，44项自动子集通过、0失败、16项待审。600—700lx是平均范围，并非每点上下限。五页目视检查和合册核对完成；E05仍展示直射诊断值，总照度在独立质量报告，图面汇总还需改进。控制线为归属示意，产品23W/24W差异、安装接线及专业适用性未验收。

284项单元回归、10项分阶段真实流程检查、实际旧请求拒绝和当前交付重放、浏览器原句展示及报告下载摘要通过。独立Python只核对公式、坐标及有限发光面直射眼部积分，不验证漫反射背景或实际产品亮度。完整记录见[脱敏验证](source-revisions-validation.json)。没有新医院外发或新医院设计；不是干净盲测、独立客户任务、多项目语义或全楼层验收，M2—M4保持未完成。
