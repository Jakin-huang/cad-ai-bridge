# 普通照明安装接线能力

此能力补充普通照明的安装路径与端子连接，服务通用 `ordinary-lighting` 任务，不按医院或其他案例名称选择算法。原有未声明安装条件的任务保持原结果。

## 输入与范围

可选 `installation` 必须显式给出 `ceiling_junction_single_pole` 拓扑、路由平面标高、配电箱端子标高，以及每个已纳入房间的开关箱位置、标高、电流/电压额定值、来源和等级。所有房间必须覆盖，且必须有 `routingConditions`。系统不根据房间名补用法或猜安装条件。

支持就地手动、区域手动的独立单极控制；一个最终回路一个独立极，可位于同一声明箱位置。感应及手动旁路不能冒充简单开关，会阻断。产品端子、LED冲击电流、接点负载类别、多联底盒容量、接头与接地做法仍须实际产品及项目依据。声明额定电流检查不代表LED负载适配通过。

拓扑由配电箱、开关上方接线点、开关、各灯上方接线点和各灯组成。馈线为 L/N/PE；开关下引线为 L/受控相线SL/PE；灯具支路为 SL/N/PE。节点端子决定连接，路径相交不构成电气连接，不共用不同回路的中性线。所有实体端点采用毫米坐标和标高。允许区域与禁入区目前是平面投影约束，不能证明三维无碰撞、穿墙或防火封堵已解决。

这一接点概念可参照[厂家单极开关接线示例](https://frpublish.leviton.com/content/dam/leviton/residential/product_documents/instruction_sheet/lc_pdf_PK-93713-10-02-2A.pdf)。该资料不作为中国项目标准、产品选型或适用性认证，开发例中的额定值也不是从该产品移植的批准参数。

## 计算与输出

原灯具布局、产品和项目限值保持。回路分组同时检查原平面估算约束、安装支路压降和声明开关电流。在既有固定灯具顺序的连续分组族内细分，不宣称任意拓扑全局最优。无可行分组或路由预算耗尽明确失败，不改限值。

支路压降考虑馈线和箱内上升、开关下行与返回、逐段下游负荷、各灯落线；沿用声明的电压、功率因数、铜电阻率和截面，属于恒定声明负荷的电阻模型。原 `extraLengthM` 作为全回路负荷下的未定位附加估量保留，单独列出，不伪装成已定位线路，不计作已审采购长度。

- E07：逐回路逻辑示意、各路径端点标高、导体端子、长度、截面和最大支路压降。
- E08：逐回路完整路径投影，端点与转折位置的坐标索引、当前房间边界及声明节点标高。
- E09：逐段W编号对应的完整V坐标顺序及Z标高，竖向段保留重复V；与E07端子表互相定位。
- `installation-runs.csv`：包含完整折线路径坐标的逐条安装表。
- `installation.json`：明确端子图、逐灯压降、导体功能分类的长度。
- HTML审核报告：并列展示原示意与安装深化结果及待审边界。

E02/E03继续表示原回路与控制归属，E06继续表示原平面基本导体估量；不能与E07安装数量叠加采购。E08/E09是安装位置与中心线的缩放表达，以坐标表定位，当前只画所属房间边界；仍需要跨回路安装总平面、实际管槽与节点做法，不能称为已完成施工图。

## 变更、验证和退出标准

安装条件进入文档目标、条件依赖、任务范围变化、建筑替换和共享空间冻结值。来源退役后必须重新解释，假设不得因任务书替换升级为已确认。房间增删、拆并或控制方案变化后的条件缺失会阻断，不能沿用失效安装位置。

生成器的检查之外，独立端子图验证关断相线、N/PE连续、开通后灯具连通和电源隔离；从端子路径累积电流并重新计算压降。另用Python节点电导方程复核实际保存模型及交付CSV，不使用生成器的计算结果作解。

本机退出标准是：手算与故障注入通过；两设计包/历史回归通过；现有九空间、65灯和全部原限值不变；真实CAD保存重开；安装图和CSV与模型一致；逐页PDF检查；旧成果保留。通过这些检查仍不代表独立客户理解、完整照明专业、真实产品适配、现场敷设或专业审核通过。

原项目ARCHIVE、SUPPORT缺少用途和条件，按冻结任务书继续保留两项缺口，禁止自行布灯凑满覆盖。医院对照完全不参与此开发验证。冻结v2包保持不变。
