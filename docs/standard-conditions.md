# 项目事实与标准适用条件

本轮把“标准表的数值约束”进一步连接到“该类别的适用前提”。导入的普通照明规则可以声明事实定义和 all/any 条件，复用通用 scope 三态判断。项目名称和标准表名不参与事实判断。未登记条件的旧规则保持兼容，也不代表其法律或项目适用性已验收。

事实来自当前任务固定的来源审阅记录。boolean、number、text、单位和解释等级都必须吻合；未知或假设不能升级成已确认值。条件不符或未知会阻断所选类别，Agent 的 next_step、设计、评估、采纳和出图共用该证据。data 的 standard_conditions 分页提供事实原句、来源身份和逐项判断；换版使旧任务失效，不能读取项目最新事实来替换旧任务依据。设计后独立重算条件，项目与标准数值取较严交集，原项目要求保持原值。

**开发验收**包含类型/单位、all/any、未知/假设、不适用、来源角色、任务绑定、分页快照、模型证据篡改及来源换版。公共判断没有医疗项目分支；当前专业接入仅普通照明，空间规划及其他专业标准还未接入。

**本机 CAD 验证**采用控制脚本明确提供的合成交通空间、既有导入标准子集和公开厂家 IES，不是 Agent 自主理解试验。未知任务停止且无模型/出图；新来源确认条件后另建任务，保留旧任务和输入。原要求 80lx、均匀度 0.40、8W/m²不变，有效计算采用 100lx、0.60、4W/m²；结果23盏灯、约104.0lx、均匀度0.660、3.953W/m²。43项设计检查和11项独立成果核对通过，仍有10项待审。实际DWG保存及重开核对通过；五张审核PDF严格解析、原件/审核件逐像素一致并逐张查看。本验证使用fields_only来源策略，不能声称原文18段已完整解释覆盖，也不替代原文到图面语义验收。

首轮全量回归因旧能力列表断言未包含新增standard_conditions失败，更新该断言后重跑。首轮本机报告脚本在出图完成后误读不存在的state.audit字段；修正为独立重算，并只读复核已有成果，没有重复出图。独立核对初次误用空间规划的通用图面核对器，随后采用照明的实际交付投影和专用核对器。原报告、原CAD/PDF及失败日志均保留。

**真实 Agent 验收尚未执行**：本轮拟用当前已登录Codex的模型服务完成“原文未知→停止→明确补充来源→重新准备→设计/CAD”两阶段测试，自动审批拒绝了额外测试输入的传输，正等待专项授权。可运行测试入口已纳入源码，不能把入口开发完成记为Agent通过。未发送医院图纸、客户资料或标准全文，也没有绕过审批。

本轮作为源码增量提交；冻结v2.0、原插件和发行包保持原样。独立委托语义、跨模型、外部用户、新机器及专业审核仍未验收，M2—M4和总体复杂工程目标保持未完成。下一优先级是完成上述真实客户端试验并检查来源事实解释及换版重准备；随后验证未参与开发的多文档项目条件，不继续堆叠同一案例。
