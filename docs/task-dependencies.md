# 通用依赖、约束一致性与变更影响

2026-10-21源码增量，沿用[通用任务入口](engineering-tasks.md)。目标是让审核者核对“哪个来源支持哪个要求、要求变化后哪些成果失效”，不是把有向图或检查通过当成理解工程或专业合规完成。

## 实际实现

通用模块管理source、requirement、condition、standard、design、check、artifact、review、result和comparison节点，以及声明的dependsOn。节点保存值、依据状态和来源角色；产物节点明确available，尚未形成的模型或尚未记录的审核不会被计作已作废成果。项目UUID和任务摘要参与图身份。图最多5000节点、20000边；重复/缺失节点、重复边和环会拒绝，不截断后宣称完整。

依赖按适配器映射实际持久化状态：照明映射来源、逐房间要求、条件、标准记录、模型、独立模型检查、可选光度报告、当前交付和审核；图纸分析映射源图、完整捕获、显式规则、结果及CSV。专业字段保留在各自适配器。当前设计模型采用所有输入的保守依赖，变化后全模型重算；没有实现逐对象选择性原生更新或自动推断漏写的依赖。

标为reference的来源只能流向comparison节点，不能经要求、比较结果或其他节点回流生成。这是对**声明角色和依赖**的检查，不能识别伪装成input的最终图内容。医院成图与生成输入的真实隔离仍须依照原案例文件清单和摘要逐项核对；本轮没有重新读医院资料或将医院对照接入这个图模型。derivedFromFinalDrawing保留回溯标记，不变成独立输入。

通用标量约束只处理同一subject/property/unit下的数值上下界、相等值和字符串相等。类型混用或单位尚未统一会阻断敏感计算，不自动换算；没有多物理量推理、空间约束求解或任意标准文本执行。照明适配器在设计、求解、光度复核、优化、采纳和交付前检查声明约束是否矛盾，原专业引擎的更严格闸门继续执行。

标准记录分别保留inputClaimsVerified和实际导入证据。输入端声称verified不能升级成source_bound；后者只表示相应模型记录的来源绑定，不是专业适用性、现行有效性或审核批准。文件或任务书换版仍要显式接入；依赖查询不是未登记外部文件的监控器，也不自动将修改后的原文件替换为冻结输入。

## 操作与审核

新增cad_engineering_task动作dependencies，身份参数与status相同。view=current读取当前图，view=impact配operationRequestId读取某次已登记操作的前后影响；offset/limit分页，续页携带首次返回的graphSHA256作为expectedGraphSHA256，防止拼接不同版本。单页另限256KiB；超大单项明确报DEPENDENCY_ITEM_TOO_LARGE，须查看已保留的本地快照，不返回看似完整的裁剪结果。只读MCP保留这些读取，隐藏prepare/invoke。

每次新操作冻结前后依赖图及影响JSON，记录摘要；影响查询重新核对两图、摘要和完整差异。差异使用前后两套边计算，能追到被删除的旧产物。已有原生文件原样保留，失效表示退出当前版本及需要重新核对，不表示删除历史。模型自身摘要匹配但仍引用旧输入时也会拒绝。

新增操作另输出UTF-8 BOM影响CSV，并通过execution.dependencyFiles登记文件摘要；MCP把该收据的影响清单与当前设计文件链接分别呈现。CSV优先展示原值、新值、单位/约束、依据和受影响前序；防止表格公式执行，长字段明确标记截断，完整值在同操作JSON中。历史收据没有这些字段时不会补写或伪造；可对经过摘要核对的旧影响JSON生成独立派生CSV，注明来源。

## 本轮本机证据

预先构造的办公基线和R1修订指令均按原文件摘要登记。实际MCP执行300lx/就地手动的R0，记录一份明确标为simulation的修订意见，再按已声明R1改为400lx/区域集中手动。依赖影响保留两项原值/新值和来源，退出当前版本的已有成果为1模型、1模型检查、17项交付文件和1份模拟审核；不是17张图，也不是真实专业签审作废。

R0为9套/216W、估算324lx，R1为12套/288W、估算432lx；均为1回路、五张A3。两版实际CAD保存重开和逐图输出完成，10页图幅、渲染及目视已核对。旧文件、旧模型和两份来源保持原字节；新版说明显示区域集中手动，施工敷设仍待深化。另复用既有已知合成原生捕获，验证同一依赖模块在非照明的24m边界统计中可用，不把该分析算第二类复杂设计。

13项真实流程检查、10项最终源码MCP重放/分页/CSV/只读检查及327项全量单元检查通过。新增CSV后只做无CAD的报告传输回归，原生历史收据不改；测试对CSV引号格式的错误断言修正后复用已存在任务和收据完成核对，没有重跑CAD。原生PDF仍保留AutoCAD重复PageMode键的解析警告，10页均可解析、渲染，未改写原PDF掩盖诊断。

全量回归发现上一轮在回归之后新增的Skill引用越出了可安装Skill目录，导致11项安装检查失败。已把外链改为自包含说明，未放宽安装器；最终326项包含安装、升级及回滚检查，旧发行包和全局客户端安装不变。原失败日志保留，不能用前一轮的316项结果替代本轮最终源码验收。脱敏记录见[验证明细](task-dependencies-validation.json)。
