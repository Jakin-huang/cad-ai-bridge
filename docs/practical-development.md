# 四阶段实施与验收记录

更新日期：2026-10-20。目标产品为 CAD AI Bridge，AutoCAD 是已验证宿主，天正为专业扩展。四阶段在v0.5.0-preview.1完成限定范围开发与本机验收；后续P0和v0.6增强的实现、实际测试与待验收项在下文单独记录。最新[脱敏验收摘要](practical-validation.json)与版本对应；早期[对标](open-source-benchmarks.md)与[计划](connector-plan.md)用于记录决策依据。

## P0与v0.6实用增强

本轮以减少调用、明确校验和大图交付为范围，不扩大未经实测的宿主。版本安排为v0.6.0-preview.1；开发状态、本机验收和产品实用性验收是三个独立结论，自动测试数量不折算为用户人数或成功率。

P0增加工作流delivery，可在一次编辑后生成全根层CSV和最终PDF/PNG；response=summary减少模型收到的明细，完整证据仍保留。Skill指导按任务发现工具，避免重复诊断和复核相同结果。允许场景显式声明一次内置图层0，cad_session的status为list别名；诊断测试当前工作目录与数据目录的可写性。真实客户端首条任务需要另测，不预先宣称提速或零纠错。

通用工作流公开JSON契约从25290字节缩减为8793字节，具体编辑操作参数按需从cad_edit发现；执行层仍完整严格校验，任意命令和未支持操作在启动CAD前拒绝。已有最终PNG时默认省略重复前后两次打印；边界完整的模型根层复合交付PNG自动增加留白，显式region不被改写。已有已认证且插件匹配的会话通过管道复用，避免为重复连接重新进入忙碌COM。图片呈现失败、最终任务日志损坏/写入失败仍返回已知保存结果；恢复入口保留任务文件和摘要，不自动重放写入。

普通工作流写入前取得DXF，写入后独立重开。保留检查覆盖未选中的ENTITIES/BLOCKS记录，包括未选中实例的属性与SEQEND。明确选中实例及其属性/SEQEND不作为未选中内容；尺寸匿名块命名和整体纸空间屏幕视口采用既有、受测试的规范化。表、字典、厂商内部关联及未读出的数据不属于完整数据库保留证明。移动、旋转、均匀缩放、复制、镜像、阵列、删除、直线修剪延伸、主要新增几何和尺寸按保存后的锚点/顶点/长度/数量核对；这不覆盖所有朝向、样式与对象语义。offset等尚无独立几何后置检查的项在review.pendingGeometry中列出。验证失败保留已保存DWG，不能据此重放修改。

v0.6新增cad_scan_drawing：一次只读捕获并建立本地索引，默认只返回摘要。最多100000条，遍历预算100000；嵌套预算和读取错误仍明确报告，截断不允许完整统计或已验证编辑。cad_read_result按filter/fields分页，并可绑定expectedResultSha256；后续分页不启动CAD。索引有独立摘要，损坏时拒绝使用。它是打开时冻结的文件快照，不会自动同步人工修改。

真实工程图补测发现变线宽LWPOLYLINE不能通过ConstantWidth读取：旧路径分别漏读58和53个对象，并如实标为不完整。修正后保留实际segmentWidths和variableWidth，恒定线宽仍返回width；嵌套逐段宽度标为definition_segmentWidths，不冒充世界宽度。该修正需要重新编译DLL并重跑回归；只使用匹配最终DLL的报告。三张本地真实大图的数量、错误数、逐段宽度DXF抽检和一张毫米图的受约束文字副本检查，另列在验收摘要的realEngineering中，不等同于外部用户试用。

统计增加显式exclude.layers/handles/blockNames/regions，报告排除数。只对具有世界坐标length字段的对象汇总长度，同时报告无此长度的数量；嵌套definition_长度不混为实际工程长度。图例和重复视图仍需明确排除，图面计数不自动变成系统拓扑或采购净量。复合交付CSV针对保存后的全部已捕获模型根层并应用排除规则，不只统计被编辑对象。

PDF支持A4—A0、横竖方向、适应或固定比例、已安装CTB；参数传入实际PlotEngine，核对宿主比例设置及PDF最终显示页大小，包含继承的页面旋转。实际渲染曾发现ISO介质本身横向时再次旋转导致方向错误，已按介质真实尺寸选择旋转，避免仅检查MediaBox而误判。固定比例只支持明确毫米制Model，并使用保守10毫米边距检查范围；放不下或CTB缺失时明确拒绝。已有布局视口的工程比例、所有字体外观、字形缺失和实际图框合规仍需独立验证，不能由页大小核对推导。

自动专项入口为node tests/practical-v06-integration.mjs，使用自建6204对象图：一次捕获、60页6000条线、图例排除、一次复合交付、保护内容对照、连续几何操作、原点不变的块旋转，以及A0—A4横竖共10种出图和错误打印参数。tests/plot-pdf-physical.py另用独立PDF解析器核对显示方向、线段方向与1:10/1:100纸面长度（容差0.05毫米，涵盖驱动量化），并以Poppler渲染人工视检合成图；这不证明任意字体和工程图合规。完整回归由scripts/verify-practical.mjs顺序执行，验收报告必须匹配最终DLL。真实客户端使用tests/workbuddy-general-skill.mjs记录相同中文任务，单次前后数据只作观察，不作为普遍效率结论。

必须外部补证的项目：至少2台机器、3名非开发用户的30项真实任务及首轮成功率；干净Windows/独立标准账户与浏览器下载信任流程；用户实际桌面中的选择、文件呈现与打开；人工对照（包含复核纠错）；长期复杂项目、厂商关联和其他CAD版本。当前环境自动验证不能把这些项目标为通过。建议的外部试用门槛为30项中至少27项无需指导正确完成，并记录全部人工介入；稳定发行需另按声明支持范围评审。

## 原四阶段通用入口与验收范围

cad_capabilities 不启动CAD，说明实际范围。cad_workflow 通过 plan.type 执行 replace_text、organize、takeoff、edit 或 export_batch。原有单项工具保持可用。

每项工作流使用一个requestId，保留冻结输入、子任务入口、成功输出和摘要。重复同一UUID与同一内容读取原结果，内容冲突拒绝；结果文件被修改时拒绝把它当成有效重放结果。大查询、读取错误或超出原子操作限额会明确停止。

文字和属性结果在保存后用新CAD进程核对。前后PNG沿用真实PlotEngine，小图作为MCP图像返回；客户端展示能力另验。变更清单覆盖本次选择及编辑所报告的新增模型空间对象，不能当作整张工程图完整保留审计。公开结果过大时保留文件清单、统计和分页入口。

只读MCP模式保留takeoff/export_batch，以及会话list/context/query/recover/snapshot；工具schema移除其写入分支，执行层也拒绝只读写入。原有写工具仍隐藏。

## 当前CAD会话

cad_session action=list列出已接入实例。没有可用实例时用connect接入正在运行的AutoCAD2022，校验PID并加载已验证插件，临时信任路径随后恢复。普通副本工作流不要求保持CAD打开。

context返回当前文档的临时身份、内存版本、保存状态、视图和选择集。query/edit/snapshot绑定该身份与版本。人工修改使旧版本请求失败；切换文档不会将操作转向另一张图。文件摘要不能替代未保存文档的内存版本。

普通编辑在AutoCAD主线程的固定注册命令中执行，使用文档锁和事务；外部桥只触发该固定入口，不能提交任意LISP或命令。命名管道限当前用户并逐请求验证令牌；令牌不进入工具结果。当前命令调度要求目标是COM可见的AutoCAD2022实例，PID不符时拒绝，不猜测其他窗口。

默认编辑当前内存文档，并另存新DWG，原文件不自动保存或改名。saveCopy=false时明确返回modified_not_saved。成功批次的正常CAD撤销和失败批次的事务回滚分别验证，不承诺任意历史操作序列的一键恢复。已经被用户撤销的请求重放仅返回历史结果，不再次应用。

recover按sessionId/requestId读取本地持久记录，无需CAD仍运行。意外错误缺少确定的事务/保存结果时返回unconfirmed，不推断已经回滚或可以重做。cancel提交取消标记，排队或提交前事务可以取消；已完成请求返回alreadyCompleted，保留输出。cancellationRequested不等于已取消，须看原请求最终结果；取消不靠杀用户CAD实现。

同一已启动CAD不能热替换不同的.NET插件二进制。接入发现旧插件时会要求正常重启该实例，不伪装更新成功。连接器退出不关闭用户CAD。测试仅清理按PID和启动时间核实的自有实例。

## 图纸兼容读取

cad_query_entities 默认仍读取模型空间根层。可提供scope.layout、scope.includeNested和scope.maxDepth选择布局及本地嵌套内容。每个嵌套实例返回instancePath，即使共用同一定义句柄也可区分。

嵌套点和边界转换到WCS；长度、半径和尺寸等标量放在definition_前缀字段，避免把非均匀缩放后的定义值当作实际工程长度。区域筛选依据转换后的包围框。外参返回识别标志，内容不自动展开。深度或遍历预算耗尽报告truncated和原因，不给出完整统计结论。

嵌套和图纸空间对象只读，不能把返回的定义句柄交给根层编辑绕过限制。单位返回数据库真实值，米制和Undefined不隐式换算成毫米。专业图面统计与采购净量的区别继续保留。

## 验收证据

离线用户候选包的14项检查、依赖修复4项、运行时故障6项、只读目录2项及中文接入后端8项均通过。发布构建另验证了4项启动器缓存失效保护；最终冻结包须保持运行时代码、插件、依赖、Skill及入口与该候选一致，另核对源码提交、清单和ZIP摘要。新机与独立标准账户仍未验收。

v0.6门禁包含115项无CAD单测、通用任务9项、实用增强12项、当前文档19项及兼容查询11项专项；当前文档另外包含30项混合操作和客户端重连。普通CAD16项、天正11项、普通/天正编辑各17项、原生桥架16项，以及旧UUID、分页、协议与实际安装配置也须回归。所有要求真实宿主的报告必须与最终DLL摘要匹配，最终结果见脱敏验收摘要。上述检查数是自动化验收项，不是外部用户人数或成功率。

新增专项入口：

- node tests/workflows-integration.mjs：五类真实CAD任务、源图摘要、图像、CSV及重放。
- node tests/session-integration.mjs：独有交互实例、实际外部COM选择/修改/撤销、多文档、取消、持久恢复与30项混合操作。
- node tests/query-scope-integration.mjs：实际嵌套、变换、外参、布局和米制读取；单位写入拒绝。
- npm test 和 npm run check -- --static：无CAD契约、边界及公开文件检查。

真实会话测试先用tests/session-host.ps1启动自有合成图实例，记录进程身份。图纸、截图、详细报告和发行暂存继续保存在项目外。核心插件变化后重跑受影响的既有普通CAD、天正、编辑、原生和兼容回归；旧报告不作为新DLL实测。

WorkBuddy5.3.8自带CLI实际读取隔离Skill，测试同一中文任务：新建两条3000毫米、间隔1000毫米的水平线，替换标题，保存重开、CSV与PNG交付，并独立核对产物。v0.5历史记录约267秒、2次参数预检纠错；本轮每次候选的耗时、调用和插件身份另列在脱敏摘要，旧插件记录不算最终DLL的客户端验收。曾有一次300秒超时，保留为失败样本；后续任务使用独立新图，不重放不确定写入。这些少量合成任务没有人工时间对照，不能证明普遍效率收益。

协议/SDK验收、WorkBuddy安装配置验收和真实桌面对话分别记录。当前新增功能不直接继承历史15工具桌面会话的验收结论。
