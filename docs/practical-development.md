## 通用任务入口

cad_capabilities 不启动CAD，说明实际范围。cad_workflow 通过 plan.type 执行 replace_text、organize、takeoff、edit 或 export_batch。原有单项工具保持可用。

每项工作流使用一个requestId，保留冻结输入、子任务入口、成功输出和摘要。重复同一UUID与同一内容读取原结果，内容冲突拒绝；结果文件被修改时拒绝把它当成有效重放结果。大查询、读取错误或超出原子操作限额会明确停止。

文字和属性结果在保存后用新CAD进程核对。前后PNG沿用真实PlotEngine，小图作为MCP图像返回；客户端展示能力另验。变更清单覆盖本次选择及编辑所报告的新增模型空间对象，不能当作整张工程图完整保留审计。公开结果过大时保留文件清单、统计和分页入口。

只读MCP模式保留takeoff/export_batch，以及会话list/context/query/recover/snapshot；工具schema移除其写入分支，执行层也拒绝只读写入。原有写工具仍隐藏。

## 当前CAD会话

cad_session action=list列出已接入实例。没有可用实例时用connect接入正在运行的AutoCAD2022，校验PID并加载已验证插件，临时信任路径随后恢复。普通副本工作流不要求保持CAD打开。

context返回当前文档的临时身份、内存版本、保存状态、视图和选择集。query/edit/snapshot绑定该身份与版本。人工修改使旧版本请求失败；切换文档不会将操作转向另一张图。文件摘要不能替代未保存文档的内存版本。

普通编辑在AutoCAD主线程的固定注册命令中执行，使用文档锁和事务；外部桥只触发该固定入口，不能提交任意LISP或命令。命名管道限当前用户并逐请求验证令牌；令牌不进入工具结果。当前命令调度要求目标是COM可见的AutoCAD2022实例，PID不符时拒绝，不猜测其他窗口。

默认编辑当前内存文档，并另存新DWG，原文件不自动保存或改名。saveCopy=false时明确返回modified_not_saved。成功批次的正常CAD撤销和失败批次的事务回滚分别验证，不承诺任意历史操作序列的一键恢复。已经被用户撤销的请求重放仅返回历史结果，不再次应用。

recover按sessionId/requestId读取本地持久记录，无需CAD仍运行。意外错误缺少确定的事务/保存结果时返回unconfirmed，不推断已经回滚或可以重做。cancel提交取消标记，排队或提交前事务可以取消；已完成请求返回alreadyCompleted，保留输出。cancellationRequested不等于已取消，须看原请求最终结果；取消不靠杀用户CAD实现。

同一已启动CAD不能热替换不同的.NET插件二进制。接入发现旧插件时会要求正常重启该实例，不伪装更新成功。连接器退出不关闭用户CAD。测试仅清理按PID和启动时间核实的自有实例。

## 图纸兼容读取

cad_query_entities 默认仍读取模型空间根层。可提供scope.layout、scope.includeNested和scope.maxDepth选择布局及本地嵌套内容。每个嵌套实例返回instancePath，即使共用同一定义句柄也可区分。

嵌套点和边界转换到WCS；长度、半径和尺寸等标量放在definition_前缀字段，避免把非均匀缩放后的定义值当作实际工程长度。区域筛选依据转换后的包围框。外参返回识别标志，内容不自动展开。深度或遍历预算耗尽报告truncated和原因，不给出完整统计结论。

嵌套和图纸空间对象只读，不能把返回的定义句柄交给根层编辑绕过限制。单位返回数据库真实值，米制和Undefined不隐式换算成毫米。专业图面统计与采购净量的区别继续保留。

## 验收证据

离线用户候选包的14项检查、依赖修复4项、运行时故障6项、只读目录2项及中文接入后端8项均通过。发布构建另验证了4项启动器缓存失效保护；最终冻结包须保持运行时代码、插件、依赖、Skill及入口与该候选一致，另核对源码提交、清单和ZIP摘要。新机与独立标准账户仍未验收。

最终候选通过91项无CAD单测、通用任务9项、当前文档19项及兼容查询10项专项；当前文档另外包含30项混合操作和客户端重连。普通CAD16项、天正11项、普通/天正编辑各17项、原生桥架16项，以及旧UUID、分页、协议与实际安装配置回归均通过。所有要求真实宿主的报告与最终DLL摘要匹配。上述检查数是自动化验收项，不是外部用户人数或成功率。

新增专项入口：

- node tests/workflows-integration.mjs：五类真实CAD任务、源图摘要、图像、CSV及重放。
- node tests/session-integration.mjs：独有交互实例、实际外部COM选择/修改/撤销、多文档、取消、持久恢复与30项混合操作。
- node tests/query-scope-integration.mjs：实际嵌套、变换、外参、布局和米制读取；单位写入拒绝。
- npm test 和 npm run check -- --static：无CAD契约、边界及公开文件检查。

真实会话测试先用tests/session-host.ps1启动自有合成图实例，记录进程身份。图纸、截图、详细报告和发行暂存继续保存在项目外。核心插件变化后重跑受影响的既有普通CAD、天正、编辑、原生和兼容回归；旧报告不作为新DLL实测。

WorkBuddy5.3.8自带CLI已实际读取候选Skill，完成中文通用首条任务：新建两条3000毫米、间隔1000毫米的水平线，替换标题，保存重开、CSV与PNG交付；6项产物核验通过。该客户端过程纠正了2次参数预检拒绝，总时长约267秒，包含模型调用与真实CAD；这是单次合成任务记录，没有人工时间对照，不作为效率提升证明。

协议/SDK验收、WorkBuddy安装配置验收和真实桌面对话分别记录。当前新增功能不直接继承历史15工具桌面会话的验收结论。
