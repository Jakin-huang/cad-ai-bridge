# v2.0.0-preview.1

本版从 v0.6 一次性集成到 v2.0，以用户预览包交付。内部 npm/插件兼容版本保持 0.2.0，外部发行版本是 2.0.0-preview.1；旧请求分支继续回归。已完成限定范围的实现和本机验证，稳定实用性验收仍未完成。

用户解压完整的 cad-ai-bridge-2.0.0-preview.1-windows-x64.zip，运行“开始使用.exe”完成接入；“任务中心.cmd”提供本地任务入口。包携带官方便携运行时、锁定依赖及项目插件。最终包按本地 Git 标签冻结，ZIP 摘要由同名 .sha256 文件提供；未自动上传或发布远程 Release。

## 新增交付

- cad_project：预先冻结多图输入，逐图执行与保留副本，真实阶段、图间取消、检查点恢复；保存状态不明时不自动重做。失败出图可独立只读重导。
- cad_analyze：完整冻结查询上的工程规则和计量，记录版本、单位、系数、损耗、进位及对象/实例路径。缺项时保留部分量，不伪造完整物理总量。
- 本地任务中心：中文浏览器入口、项目提交、历史与进度、分级验证、CSV/图纸下载及 PNG 预览；无远程账户，服务仅监听本机并验证访问令牌。
- 验证层级：执行、源图、保存、独立重开、几何、保护、渲染、视觉和交付分开报告。旧结果不补写不存在的证明，partial/unknown 不称完整通过。
- 常见二维对象：新增文字高度/宽度/方向、图块基向量与镜像方向、SOLID 顶点、折线弧度及部分表状态独立检查。
- 一次原生宿主内批量 PDF/PNG，逐项失败保留其他输出；编辑后独立重开验证仍保留。
- 后端扩展契约和固定分母评测工具：适配声明、实际运行证据和竞争结论分别处理。

## 本机验证与实际观察

- 150 项单元测试通过，无失败或跳过；完整回归的 26 个有效步骤通过。旧失败及被替代记录保留，不累加为成功次数。
- 新 v2 核心集成 7 项、MCP 专项 9 项，覆盖保存几何、源图绑定规则计量、项目恢复、分页及可直接复制的文件交付链接。另保留原通用、会话、保护、兼容回放和天正专项。
- 三个本地真实工程案例分别捕获 34980、61437、39048 个对象，读取无错误；第三例进行了受约束文字编辑并独立重开核对，原图未改变。第二例单位 Undefined，只读捕获不解释成物理工程量。
- 一次真实 WorkBuddy CLI 中文通用任务用时 157347 毫秒，3 次 Bridge 调用、12 次客户端函数调用、5 次 CAD 启动、零参数验证错误，交付 DWG、两份 CSV 和 PNG。先前一次确实缺少可点击链接的失败保留；修复后的运行已在用户可见回复中给出四个正确链接。
- 客户端后续追加记忆提示，最初只读最终尾句的验收脚本误判。现以未改动的原始事件流复核最后 CAD 结果之后的实际交付消息；这是对真实运行的重新核验，不算新的模型或 CAD 执行。该运行还尝试过被拒绝的命令行和记忆写入，且有额外只读 Skill 文档检索，交互成本仍在。
- 相同输入的单宿主批量导出观察采用 ABBA 顺序：逐次启动 11224/9993 毫秒、各 3 次宿主；合批 3769/4099 毫秒、各 1 次宿主。每类仅两次，不能推导用户生产率或竞品领先。
- 当前任务中心实际浏览器验证了任务状态、分级证据、摘要匹配的 CSV 下载和 1600×1280 原生 PNG。解压包、离线升级/回退、依赖修复及打包入口的具体结果见[发行验证](../windows-user-validation.json)和[v2 验证摘要](../v2-validation.json)。
- 用户包 14 项、打包入口 5 项、依赖故障/修复 4 项、首次接入工作进程 8 项通过。入口脚本已实际发起默认浏览器启动；默认浏览器像素和下载信任提示未观察。入口验收曾因 Windows 后代进程持有管道而等待，改为等待启动器退出后通过，产品启动器未改动。

## 支持和实用性边界

本机已验证宿主基线仍是 AutoCAD 2022 中文及可选天正电气 V8，不宣称新增 CAD 版本、GstarCAD/ZWCAD/FreeCAD 执行支持。普通写入仍限明确毫米制的模型空间根对象。动态块、外参、嵌套改写和复杂厂商语义需要专门适配。

几何检查是已声明的子集，offset、部分布局/标注语义及视觉字体等未覆盖项会如实保留。项目不是跨 DWG 事务，某图失败时其他成功图仍存在。原始失败、重导和恢复记录不因后续成功而抹去。

新机器、独立标准账户、真实桌面自然语言、外部用户、长周期稳定性和人工效率尚需外部证据。本地 VM 测试继续暂缓。当前没有同条件竞争实测，不能宣称已经超越其他项目。
