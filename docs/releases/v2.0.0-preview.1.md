# v2.0.0-preview.1

本版从 v0.6 一次性集成到 v2.0，当前进入最终集成验证。最终冻结包、摘要和验收状态将在检查通过后写入本页。内部 npm/插件兼容版本保持 0.2.0，外部发行版本是 2.0.0-preview.1；旧请求分支继续回归，不用版本号替代功能与验收。

## 新增交付

- cad_project：预先冻结多图输入，逐图执行与保留副本，真实阶段、图间取消、检查点恢复；保存状态不明时不自动重做。失败出图可独立只读重导。
- cad_analyze：完整冻结查询上的工程规则和计量，记录版本、单位、系数、损耗、进位及对象/实例路径。缺项时保留部分量，不伪造完整物理总量。
- 本地任务中心：中文浏览器入口、项目提交、历史与进度、分级验证、CSV/图纸下载及 PNG 预览；无远程账户，服务仅监听本机并验证访问令牌。
- 验证层级：执行、源图、保存、独立重开、几何、保护、渲染、视觉和交付分开报告。旧结果不补写不存在的证明，partial/unknown 不称完整通过。
- 常见二维对象：新增文字高度/宽度/方向、图块基向量与镜像方向、SOLID 顶点、折线弧度及部分表状态独立检查。
- 一次原生宿主内批量 PDF/PNG，逐项失败保留其他输出；编辑后独立重开验证仍保留。
- 后端扩展契约和固定分母评测工具：适配声明、实际运行证据和竞争结论分别处理。

## 支持和实用性边界

本机已验证宿主基线仍是 AutoCAD 2022 中文及可选天正电气 V8，不宣称新增 CAD 版本、GstarCAD/ZWCAD/FreeCAD 执行支持。普通写入仍限明确毫米制的模型空间根对象。动态块、外参、嵌套改写和复杂厂商语义需要专门适配。

几何检查是已声明的子集，offset、部分布局/标注语义及视觉字体等未覆盖项会如实保留。项目不是跨 DWG 事务，某图失败时其他成功图仍存在。原始失败、重导和恢复记录不因后续成功而抹去。

新机器、独立标准账户、真实桌面自然语言、外部用户、长周期稳定性和人工效率尚需外部证据。本地 VM 测试继续暂缓。当前没有同条件竞争实测，不能宣称已经超越其他项目。

详细入口见 [v2 使用与验证边界](../v2-usage.md)，开发及验收状态见 [实施台账](../v2-implementation.json)。
