# v0.2.0-preview.4 · 2026-10-19

新增已有图纸查询、批量编辑与真实CAD出图，保留原15个工具、原图保护、回滚、幂等及MCP/Skill接入方式。新版本共18个工具，用户仍双击“开始使用.exe”，无需新增配置步骤。更新后在客户端重新连接以发现新工具。

- 对象筛选、普通对象移动/复制/旋转/缩放/镜像/阵列/删除，文字、实例属性及图层修改。
- 在已有图纸补画与插入普通本地图块，曲线偏移、直线保留段修剪和延伸。
- 非关联尺寸、命名视图、新布局和视口。
- 管理设备移动、已知路线的几何/回路/规格修改，以及自动刷新的普通路线文字标签。
- 真实AutoCAD PDF/局部PNG出图及MCP图像返回，修复中文字体被替换的问题。
- 保留旧版本已保存请求UUID的指纹形状，升级后重放不重复修改。

所有修改仍在快照中执行并另存新文件，失败整批回滚。未知关联、代理、动态图块和外参不开放通用写入。源码与发行包继续不含图纸、示例数据或预览资产。

天正原生桥架、厂家专有标注及全套原生命令尚未完成，本版没有这些能力。已有普通路线标签不等于厂家原生标注。新增能力的真实CAD/MCP验收与WorkBuddy历史桌面验收分开记录；干净Windows、独立标准账户和新增功能的桌面自然语言流程仍待验收。
