# v0.2.0-preview.6 · 2026-10-19

补齐天正V8独立直线槽式桥架创建、尺寸/目录型号同步及原生关联标注，保留原有18个工具、接入入口、原图保护和已验证编辑能力。[原生范围与契约](../native-trays.md)

修复用户ZIP验收发现的原点终止问题：V8原生命令在第二点为WCS原点时未正常结束。桥梁在内部交换这类无向桥架的两端，绘制几何保持相同，用户无需调整坐标或增加步骤。原请求对象不被修改，任务指纹使用实际规范化计划，保存后UUID重放仍保持幂等。

实际记录已确认，非原点的反向、竖向、负方向和斜向输入可直接执行；原点终点则走规范化。普通用户继续使用“开始使用.exe”、原连接器和全局Skill，无需新增依赖或配置。

preview.5保留为未通过完整用户发行验收的冻结候选，不能作为本版通过验收的替代。修复不改变已验证的CAD插件二进制；原生专项重新覆盖反向至原点请求，发行包另验随包运行时、真实绘图、完整Skill升级恢复及依赖修复。

支持范围仍为独立、平面、直线槽式桥架；不包含连接弯头/三通、其他系列、自动绕障和厂家全套统计一致性。干净Windows、独立标准账户及新增原生能力的桌面自然语言对话仍待独立验收。
