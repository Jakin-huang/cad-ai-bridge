# v0.2.0-preview.2 · 2026-10-19

本版完善普通用户接入：收到压缩包后，无需了解 GitHub、MCP 配置或开发环境，即可选择图纸目录并接入 WorkBuddy。项目继续作为已有 CAD 与 AI 之间的连接器，绘图能力和数据保护规则保持原有范围。

## 开始使用

获取 `cad-ai-bridge-0.2.0-preview.2-windows-x64.zip` 用户包并完整解压到自己的固定目录，双击 **开始使用.exe**，选择图纸文件夹，点击“接入 WorkBuddy”。根目录附有可离线阅读的[一页图文说明](../../使用说明.html)。

本机准备成功后，窗口会引导用户在 WorkBuddy 的“自定义连接器”中完成首次信任，等待工具加载，并确认当前任务选用了连接器。可直接点击“复制第一条任务”，粘贴到 WorkBuddy。准备完成不等于客户端已连接。

## 本版变化

- 增加中文窗口入口和随包的轻量 Windows 启动器，直接使用系统 Windows PowerShell 5.1 与已有 .NET Framework，不要求另装界面框架、账号或常驻程序。
- 图纸目录可通过系统文件夹选择器点选，首次默认文档目录；重复接入沿用原有目录，升级保留已有选择，换目录无需输入命令。
- 显示准备进度、中文成功/失败状态和下一步处理办法；日志单独保存在用户目录，需要时再查看。
- 完成状态与配置摘要绑定，配置被手动修改后不显示旧的成功状态；无效或不可写目录在改动连接器前停止。
- 新增离线图文说明和可复制示例任务。命令行入口保留给脚本、开发者及其他 MCP 客户端使用。
- 用户包清单绑定启动器、对应源码和离线说明，并继续核对全部文件 SHA-256。

## 验证与范围

普通 AutoCAD、天正和 WorkBuddy 的既有验证范围延续上一预览版。新版补充真实安装后端的中文、空格、单引号路径，目录记忆/更换，配置保护和失败恢复验收，并检查原生窗口状态的布局。绘图和升级回退仍通过独立解压包进行本机测试。

实测范围是 Windows 10 x64、未提权进程、正常安装授权的 AutoCAD 2022、可选天正电气 V8，以及已验收的 WorkBuddy 5.3.8。**干净 Windows、独立标准账户、浏览器下载安全提示以及其他 CAD/客户端版本仍未完成验收。** 本地虚拟机验收继续暂缓。

用户入口不会替用户点击客户端信任，也不宣称内嵌 DWG 预览。学校生成仍是可选回归样本，额外需要 Python 库与本机字体。

## 升级与恢复

保留旧安装目录，在新版目录打开“开始使用.exe”并接入。需要回退时先结束 CAD 任务并退出 WorkBuddy，再运行新版目录中的 `restore-workbuddy.cmd`。恢复保留其他连接器和图纸；手改配置冲突不会被强行覆盖。[详细安装与恢复](../windows-user-release.md)

内部 package/插件兼容版本仍为 0.2.0；发行标识为 v0.2.0-preview.2。冻结包附带源码提交、标签、清单和 `.sha256` 校验文件，上一版冻结包保留。
