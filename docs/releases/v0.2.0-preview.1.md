# v0.2.0-preview.1 · 2026-10-19

CAD AI Bridge 的 Windows 用户预览版：把已有 CAD 软件能力接到 AI 客户端，通过 MCP 工具执行，配合可迁移的 Skill。近期重点是减少接入步骤、提高稳定性和效率，保留已验证的读图、批量制图和工程副本能力。

## 下载与开始

在本仓库 Releases 选择 `cad-ai-bridge-0.2.0-preview.1-windows-x64.zip` 及同名 `.zip.sha256`。解压到可写用户目录，双击 `connect-workbuddy.cmd`，在 WorkBuddy 中完成首次信任，等待工具加载后开始自然语言任务。源码 ZIP 面向开发者，不包含插件与离线运行时。[详细步骤](../windows-user-release.md)

冻结发行标识为 `v0.2.0-preview.1`；内部 package 和插件兼容版本仍为 `0.2.0`。发行包的 `release-manifest.json` 包含发行标识、源码提交和标签、每个文件的 SHA-256。用户包包含项目插件、锁定依赖及官方便携 Node 22.23.3 / PowerShell 7.4.20，不包含 AutoCAD、天正、私有图纸、图库或字体。

## 本版改进

- 一个入口完成运行时准备、连接器配置合并和全局 Skill 安装；保留其他服务，避免要求用户编译或配置开发环境。
- 缺失运行时可离线提取并校验；网络失败、损坏 ZIP、只读目录均给出可执行的恢复路径。
- 升级沿用已有图纸目录；安装事务、互斥锁与冲突检查保护配置，恢复命令可回退上一版连接器和 Skill。
- 15 个 MCP 工具支持诊断、读图、统计、批量布置、连线、编号与分页。任务中断可找回已有结果；已保存的 DWG 在后续导出失败时仍被保留，不自动重放写入。
- 保留普通 AutoCAD、天正、工程副本和学校生成样本的回归能力。学校流程是可选业务样本，另需 Python 库和本机字体。

## 验证范围

实测 Windows 10 x64、AutoCAD 2022 简体中文、可选天正电气 V8.0。WorkBuddy 5.3.8 已完成用户辅助桌面验收：连接启用、全局 Skill 发现、自然语言批量绘图、保存重开、文件卡片展示；用户确认手动打开 DWG。未宣称内嵌 CAD 预览或文件卡片直接调用 CAD。

本机未提权进程下的发行包测试覆盖离线缺失运行时、最小 PATH、中文及空格路径、依赖补齐失败与恢复、升级与回退，并用发行包执行两灯、3000 mm 路线及编号的真实 CAD 回读。[发行验收摘要](../windows-user-validation.json) · [完整回归记录](../maintenance-validation.md)

**仍待完成：干净 Windows、独立标准账户、浏览器下载后的 Windows 安全提示流程，以及其他 CAD 版本和客户端的实机验证。** 本地虚拟机验收暂缓，不以隔离目录或未提权进程替代这些证据。因此本版作为预览版发布，不宣称普遍兼容。

## 升级与反馈

保留旧安装目录，在新目录运行 `connect-workbuddy.cmd`。要恢复时，先结束 CAD 任务并退出 WorkBuddy，运行 `restore-workbuddy.cmd` 后重新打开客户端。若手动修改了本项目配置或 Skill，恢复会保留修改并报告冲突。[排障](../troubleshooting.md)
