# v0.5.0-preview.1

本版以通用 CAD AI Bridge 为主体，完成四阶段的本轮开发范围。适用环境仍为 Windows x64、AutoCAD 2022 简体中文；天正电气 V8 是可选专业扩展。发行版本为0.5.0-preview.1，内部包及插件兼容版本保留0.2.0，以维持既有UUID任务与接入兼容。

## 可直接使用的能力

- 21个MCP工具，保留原18个。cad_capabilities在不启动CAD时说明能力边界。
- cad_workflow提供文字替换、属性/图层整理、CSV统计、普通批量编辑及批量PDF/PNG；冻结输入、记录子任务、保存后独立回读、返回前后图与变更清单，并校验重放输出。
- 实验性cad_session按需接入当前AutoCAD2022，读取文档、选择集与视图；编辑绑定文档身份和内存版本，在固定命令中使用事务，默认保存独立副本。支持正常撤销、持久恢复、提交前取消以及客户端重新连接。
- 查询可展开本地嵌套块并区分实例路径，转换WCS点和边界；读取布局、识别外参、报告真实单位。深度、遍历和数量上限明确返回，截断不能视作完整清单。

## 使用与保护

保持用户图纸和测试资料在源码、发行包之外。先读取能力和图纸，再执行有明确对象范围的任务。副本工作流不覆盖源图；当前文档会话编辑内存并默认另存，仍须按结果检查保存状态。相同请求UUID只返回历史结果，不在用户撤销后重新应用。

只读模式在工具schema和执行层限制复合工具的写入分支。会话管道仅当前用户可访问，令牌不返回客户端，外部调度仅允许固定注册命令。完整契约见[工具](../tools.md)、[通用任务](../../skills/cadbridge-electrical/references/general-workflows.md)和[当前文档](../../skills/cadbridge-electrical/references/session-workflow.md)。

## 验收与限制

本轮使用真实授权CAD、合成图和官方MCP SDK，专项覆盖通用任务、当前文档冲突/撤销/回滚/取消、30项混合会话操作与重连、嵌套/外参/布局/单位；并回归原普通CAD、天正、电气、原生桥架及历史UUID。发行检查要求各专项使用最终DLL摘要，旧二进制报告不通过。

详细证据和状态以[实施记录](../practical-development.md)及其最终摘要为准。历史桌面对话验收不等于本版新增功能桌面对话验收。干净Windows、独立标准账户、外部用户试用及长期生产稳定性仍待验证，保持预览发行。

当前文档命令调度仅支持COM可见的AutoCAD2022实例，PID不符时拒绝。嵌套、动态块、外参和图纸空间对象的写入，其他CAD版本及非毫米写入不在本版范围。嵌套长度等标量标记为定义值，不冒充变换后的工程净量。天正扩展继续受[原生范围](../native-trays.md)约束。
