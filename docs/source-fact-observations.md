# 多来源事实分歧与条件依据出图

本轮收敛同一问题：多份资料对同一项目事实给出不同陈述时，保留差异、明确处置、驱动条件判断，并把实际采用的依据交到图面和审核索引。医院不是路由条件；相同逻辑接入照明和空间规划的任务条件，以及普通照明的标准类别条件。

每个scope事实可以登记最多十条observations，各自保留ID、值、单位、解释状态、理由和原文引用。没有resolution时，不同值要求汇总为unresolved/null；未明条件保持未知，一致但含assumed的陈述仍为假设，全部已解释且一致才可形成已解释汇总。填写的事实值及状态必须与重新计算的结果吻合，不能在冲突记录之外另填一个“已确认”值。

有明确处置依据时，可用resolution引用当前需求或协调原句，选择已解释且一致的陈述。其余陈述及原句继续保存，不能按文件顺序、名称、日期或角色自动判权威。规则只校核调用方提交的类型、原句定位和声明一致性，不会自动读懂所有资料、发现未登记的分歧、确认发出人的权威或作专业批准。未使用observations的旧事实保持原契约，不能据此声称历史冲突都已排查。

条件事实引用也进入新版来源索引，分别记录委托范围、事实声明、所选陈述、排除陈述和明确处置依据。E01及空间方案说明通过共用投影显示原文行号和引用性质，不再把这些实际被条件采用的文件显示为未引用背景。旧v1索引和已发图不回写；历史核对保持原样，新模型采用v2索引。字段审阅的document disposition仍与条件引用分开，不能把字段级context理解成该文件在整个任务中无用。

本机验证使用控制脚本提交的合成分歧：原要求认定某建筑功能，现状说明给出相反陈述，未有协调指令时条件保持未知且不设计；新协调指令明确选取原要求后另建任务，保留原分歧任务。23盏灯、约104.0lx、均匀度0.660、3.953W/m²，原项目80lx、0.40、8W/m²保持，43项设计检查通过且10项待审保留。本轮没有增加设计可解范围，也不是Agent独立理解或完整工程质量验收。

首轮CAD技术检查通过，但逐页查看发现E01把条件引用误标背景，内容验收失败。该版本、原图和报告保留。修正通用来源索引后，新验证完成13项独立核对，五张审核PDF严格解析、原件/审核件逐像素一致并逐张查看；新旧计算、物理方案和非说明页像素相同。两个设计包的来源换版、历史索引和旧格式兼容由自动测试验证。

本机来源策略仍为fields_only，图面如实显示原文整段覆盖尚未完成。真实Agent测试仍等待上一轮提出的新增模型服务输入授权，未再次启动客户端或绕过审批。开发、本机声明子集、独立语义、客户项目、新机器及专业审核分别记录；M2—M4和总体目标保持未完成。下一步应在授权后验证真实Agent是否完整登记矛盾与处置，而非继续增加同一已知文本变体。
