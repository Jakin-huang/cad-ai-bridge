# 建筑边界和入口来源换版

工程引擎1.13.0增加`replace_architecture`。它在同一房间ID、名称和附名用途关系清单下，用新建筑包替换明确闭合边界和声明入口锚点，撤销当前设计、复核、图纸及审核，按原要求重新生成整个声明范围。它不是选择性原生改图，不接纳任意新增/删减房间、功能变更或专业参数修改。

## 使用与来源边界

先用`inspect_architecture`捕获新版DWG，绑定文件SHA、来源身份、声明范围、房间和边界/文字层。每项`expectedRooms`现在可提供`entryInstancePaths`：入口锚点的完整源对象路径数组。只能指定有明确平面position的TEXT、MTEXT、INSERT或POINT，边界及锚点须在当前支持的Z=0平面，位置须在对应房间边界上。重复/重合、缺失、非平面或不在边界的锚点阻断完整性。入口角色由调用者显式声明，源锚点不能证明门扇、门宽、疏散功能或建筑专业已确认。

旧接入不要求入口字段以保留原语义；执行建筑换版则新包每个房间必须有来源入口，且必须是完整的观察闭合边界，不能用接受推断的选项绕过。入口源数据写入冻结空间包，完整捕获记录及包摘要继续绑定。使用者仍需提供准确的项目清单及源对象分配；当前没有任意大图自动识别门和房间用途的能力。

`replace_architecture`精确字段：action、jobId、requestId、expectedRevision、expectedInputSHA256、architecturalPack、supersededSourceId、description。architecturalPack为jobId、sha256及可选acceptInferredGeometry。新sourceId取自新包，必须新且唯一，文件内容也须不同。原来源保留SHA及替代关系；新来源的声明/历史属性继承该建筑包，不通过换版把旧派生资料洗成独立客户输入。

边界、入口、图面建筑线和附名对象位置按新包更新，要求、产品、电气、净高、工作面、障碍和功能分类保持冻结。标准、供电、产品、需求或功能分类若仍依赖被退役建筑来源，操作拒绝，必须先取得相应专业条件的新权威依据；不能把新几何SHA当成这些条件的证据。旧缺项与注记继续保留，入口语义新待审项追加，不能通过换版删缺项。

## 一致性和审核

每次变更记录前置修订/输入摘要、新旧来源、建筑包及逐房间条件摘要链。状态查询与后续操作重读所有登记变更引用的捕获、包和归档输入，按原输入重放确定性几何替换，再核对当前几何、入口和保留尺寸。改写当前输入及其摘要也不能绕过源绑定。连续建筑版本保留完整链；当前请求重放不倒退已设计/已交付状态，旧请求在后续修订后拒绝。文件发布日志不等于真实CAD中断恢复认证。

任务书先前逐字“沿用”记录保留原字节；新建筑的几何取代由独立变更链解释，不能伪造旧原句或改写旧摘要来声称几何没有变化。任务书再次换版仍执行原保守失效规则。当前只支持上述明确来源角色及冻结参数组合，不宣称一般多文档语义冲突已解决。

`status`使用`{action:"status",jobId,section:"architecture_changes"}`读取影响、历史来源、最新面积/入口位置和来源对象路径。任务中心优先展示工程数值，摘要留在展开的来源核对中。CAD说明显示当前/历史建筑身份、变更房间数、全范围重算及入口语义限制；独立检查和原生保存重开继续核对同源输出。

## 本机证据与未完成项

本轮复用既有已验证的12间合成办公室楼层及其历史原生交付。显式构造新版真实DWG，将两间边界宽度改为9m、6m，入口分别移至x=3000mm、12000mm。实际捕获12个边界及12个源入口后，面积从各48㎡改为54㎡、36㎡，其余十间48㎡。一份缺失入口源对象的负例实际被阻断，不能更改既有设计状态。

原项目要求、产品、电气和净高/工作面未改。全范围重算由108套变为107套假定24W灯具，12回路、总2568W，5页输出：说明/系统/计算A3，平面/控制A1、1:100。新面积对应10套/7套及利用系数估算320/336lx，其他房间9套、324lx。该变化是有界布局求解结果，不是测量节能、最优证明或实际厂家选型。

292项单元回归及11项真实MCP/CAD流水线检查通过；独立模型子集228通过、0失败、17待审。新旧源图、历史模型和原交付摘要未变，模拟审核失效。五页物理尺寸、逐页目视及合册像素核对完成，浏览器工程数值和当前计算CSV下载摘要匹配。详情见[脱敏验证](architecture-revisions-validation.json)。

本用例不含IES、反射、逐点均匀度或UGR验收；使用声明的普通照明估算及测试规则，不能替代适用标准全文和产品质量。源入口仅锚点，尚未构造真实开口或施工接线。两次建筑变更、建筑与任务书沿用链的兼容及当前输入摘要篡改阻断另有控制器测试，不能称这些组合全部做过原生/真实客户端验证。没有新医院外发、新医院设计、独立客户或未见项目验收；M2—M4继续未完成。

下一步优先整层真实光度/总照度计算的预算和分区、医院空间/功能缺项闭环与独立输入；随后推进房间清单/功能变化、电气/净高等专业条件换版、工程图面质量摘要和施工深化。外部用户、新机器及真实专业审查分别验收。
