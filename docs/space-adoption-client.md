# 真实 Agent 的空间换版采纳与照明重算

2026-10-24，本轮补齐照明任务的只读数据入口，使真实 Agent 能通过公开工具取得实际输入和冻结条件摘要，自行完成空间上游换版后的保守采纳。此前联动测试由控制脚本计算摘要，不能证明客户端只靠工具即可完成。新增能力不识别医院、学校或办公名称，不替调用者分类用途、选择标准或批准条件延续。

`engineering_task capabilities kind=ordinary-lighting section=data` 现在提供三个分页 section：

- `input`：当前真实输入的字段目标、值及摘要，包括 brief、空间、要求、来源、产品、假设及缺项。
- `space_adoption`：当前 expectedRevision/InputSHA256/ConditionsSHA256、原空间绑定、上游当前性及冻结条件值。摘要算法与旧采纳协议相同；不能将它当作同意延续条件。
- `space_program_changes`：已保存的采纳/修订历史。

沿 hasMore/nextOffset 读取，用 expectedDataSHA256 固定同一 section 的快照。读取不写文件、产生任务、运行 CAD 或升级审核；页及单项有256KiB预算，单项过大明确拒绝。revision 仅接受当前版本，不冒充历史输入迁移；旧文件继续保留。输入、来源或上游在读取期间改变会拒绝不一致的快照。未绑定上游的任务也能读自身输入，但不能借该读取获得采纳资格。

实际使用仍由 Agent 复核同生产者、同空间清单、原用途和独立照明条件是否保持，再提交 adopt_spaces 的 binding、逐空间新 functionSHA256/原句、use/reason 和明确 carryForward。新增/删除空间、用途或依据变化继续走完整修订；失效的 scope 和文档约束不因读取而解除。本轮没有增加同任务 scope 迁移能力。

本轮真实客户端验证采用新隔离目录中的已知合成项目：控制脚本建立空间方案及旧照明设计，明确把 OFFICE_A 从4席、32—42㎡需求修改为6席、40—54㎡，形成新的上游方案。上游设计是授权的输入，不是医院最终对照；未使用任何客户或医院材料。控制脚本没有把采纳 binding、冻结摘要或修订意图提交给客户端。

真实 Agent 仅用 CAD 工具读取当前照明、冻结条件和全部11项新上游空间，自行提交采纳，在同一照明任务从R0推进到R1，重算5个选定空间并实际保存重开DWG、出五页审核PDF，最后汇总两个任务的待审包。31次调用零协议错误，独立的26项机械核对通过；这次子集全过程通过不抵扣此前其他试验的失败。

新旧 OFFICE_A 的实际净面积为36.34→47.88㎡，席位4→6；全部5个选定空间重新计算，照度目标、产品、电气及其他冻结条件与假设等级保持。两版灯具总数均为41，并不表示布局未变；输入、模型及位置随新空间重新生成。新照明有101项实现范围内检查通过、52项待审。空间和照明新版共十页审核PDF经严格解析、图幅/源审核像素核对，全部逐页查看；上游空间新版由控制脚本生成，下游新版由实际Agent执行，两者分别记录。

项目待审包明确六个上游空间未纳入照明，设计/交付覆盖为false，保留119项问题。它是部分专业待审包，不是完整多专业设计。221份换版前文件均核对：七个当前生命周期视图发生预期变化，原字节在完整前镜像中保留，旧输入、模型、DWG和审核PDF保持。整个工作在新目录进行，不修改前轮封存案例。

验证工具自身的首次错误也保留：首次审阅没有按真实契约归一化请求、没有应用既有图面标签投影，导致两项错误判失败；首次PDF脚本用原始路径字符串比较Windows混合分隔符，错误地把允许变化的生命周期文件纳入不可变清单。修正只读验证器后另存报告，未改Agent结果、设计、数值或图纸，首轮报告/渲染不覆盖。

608项全量回归通过，0失败、0跳过。客户端阶段耗时约141秒，不含控制脚本建立旧设计与上游变更。CLI报告累计输入1,003,468 tokens，其中缓存输入896,000，输出3,247；这反映重复上下文负担，不能据单例宣称低成本或效率领先。后续按任务阶段减少无关参考和重复数据，仍须保留实际条件审阅与来源门槛。

开发和上述已知子集本机验收已完成；独立客户任务理解、真实现场/标准适用性、完整光学质量、复杂专业协调、跨模型、外部用户、新机器及专业签审仍未通过。该案例使用结构化旧任务、无独立客户原文文档集或 scope 迁移，不代表从任意原始委托完成全流程。原v2.0冻结包及发行版本不改变，M2—M4和总体目标保持未完成。详见[验证摘要](space-adoption-client-validation.json)。
