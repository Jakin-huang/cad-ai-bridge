## 验证项目与边界

首轮采用本地医院工程中的一个普通照明专项；优先选择六层病区，最终房间范围由建筑资料完整性决定。它必须产生新设计、计算、回路/控制关系、成套图纸及审核包，不能用文字替换冒充设计。病房、医护工作区、走廊等分别解释；特殊医疗场所、应急消防、医疗 IT、电源可靠性及配电保护协调单列适用性和待审事项，不把普通照明计算外推成医院全专业设计完成。

最终设计 DWG 是对照，不是生成模板。原始资料按 SHA-256 冻结；建筑条件、项目要求、规则、产品假设和最终对照分开存放。生成器只接受允许的建筑输入与已解释需求，不读取对照灯位、回路、灯具数量及原有照明计算。比较在设计模型摘要冻结后执行，不自动追改至贴合参考。原始客户任务书、独立建筑底图或灯具光度文件缺失时明确标记。本轮建筑条件从历史成图剥离，因此属于回溯复现测试，不能称独立盲测或新客户设计验收。

历史校审单、评分表和最终图都可能包含错误或不同时间的标准版本；对照相似度不等于正确率。校审问题可作为有来源的需求，最终图作为结果比较；标准按设计基准日期解释，不以今天版本机械否定历史设计。

## 关键技术和验收约束

工程项目保存版本化任务书、建筑模型、需求图、设计依据、计算、设计决策、CAD 身份、检查、比较及审核状态。AI 负责解释资料与形成候选约束；确定性模块负责校验、计算、生成与证据核对。既有学校生成器可复用基础几何、符号或计算方法，但不能将固定学校配置改名为医院设计。

利用系数法估算记录公式、流明、维护/利用系数及出处；假定产品、未知吊顶及反射率会进入待审清单。电流与压降是明确输入条件下的估算，不代替短路、选择性、敷设修正及医疗供电设计。支路、开关控制、设备表和系统图必须从同一个设计模型生成，并由独立读取核对。

标准登记包含编号、版本、适用日期、来源位置、内容摘要、已核验/未核验状态、适用房间和可执行检查。检索到标准名称或公告不能冒充条款全文已核验。无法访问全文、不适用和需要专业判断分别报告；本地标准全文和医院资料不进入公开仓库。

本轮主要指标是需求覆盖、设计对象与关系正确性、交付完整性、未决问题、原图保护与真实 CAD 复核。医院参考结果用于结构和差异比较；不追求逐灯位机械相同，不输出未经独立专业审核的“医院施工图合规通过”。

## 输出与完成口径

公开仓库保存通用引擎、契约、算法、测试及脱敏状态。本地资料区保存原图、抽取数据、客户材料、完整标准、生成图纸、原始日志和审核包。最终交付应包括实施状态、可打开的设计 DWG、各图 PDF/PNG、设计说明、计算、设备与回路清单、标准/需求追踪、自检报告、与最终对照的差异，以及人工审核清单。

整体方向固定为复杂工程任务设计交付；首轮专业范围是形成真实证据的边界。后续优先解决可迁移的真实阻断，并用不同任务验证；医院缺资料保留为案例待审，不得让所有后续工作停留在医院专项或同一照明算法。

## M2 建筑接入与整层出图增量

本轮已经实现 `inspect_architecture`，按布局根实体限定遍历，再按声明的空间清单、标签层和边界层核对。它返回根实体命中、遍历预算、读取错误和外参排除记录。明确闭合直线多段线可建立有来源的空间；同名房间须绑定完整实例路径。缺少边界、额外未分配标签/边界、重叠、非平面、自交、开放或曲线边界会阻止完整性通过。矩形推断另列待审，禁止把推断改称建筑已确认。

本地建筑包绑定原图摘要、原始捕获摘要和登记结果摘要；需求种子只引用该包接收几何，不让模型重复输出或任意改写坐标。设计模型和待审 HTML 保留建筑证据。工程平面保留真实毫米坐标，按范围选 A3/A2/A1/A0 与标注比例；超过 A0 1:200 仍须显式划分。新增独立检查核对纸面边界、建筑线、回路线和控制关系的实际生成结果，遗漏线段的故障注入可以被检出。

当前本机验证包含182项单元检查、12项真实 stdio MCP/CAD 建筑流水线检查，以及原 v2 核心7项和医院局部13项回归。独立合成的12房间源图生成108套灯具、12回路、5张图，平面为A1 1:100；保存重开、导出摘要、物理图幅及5页渲染均核对。它验证来源绑定和出图能力，不是新增真实医院整层或客户项目验收。

医院选定建筑根块现完整遍历4434个对象，无截断或读取错误。43个来源标签候选空间中，39个为矩形推断、4个未解析，另有3组推断区域重叠；多功能电梯标签可能引起同空间多名，需要建筑解释，不能直接判定原设计空间错误。该案例仍阻止整层设计输入。局部完整捕获解决了遍历预算问题，没有解决独立建筑来源、空间表、入口和吊顶资料不足。

本地标准汇编已只读提取，发现照明、医疗建筑电气和综合医院相关书目；全文、版本、条款表格与适用性尚未验收。下一步继续核对来源和适用日期，开展真实光度解析及独立计算对照，并完善建筑空间解析；不得把目录发现计作标准规则覆盖。新机器、外部用户、真实专业审查及M2—M4退出条件保持待验收。脱敏证据见[建筑接入验证](architectural-intake-validation.json)。

## M2 真实光度驱动设计增量

新增模式 `photometricDesign.method=ies_direct_point` 使用本地摘要绑定的厂家 IES Type C 光强表，按原测试坎德拉和维护系数计算水平工作面上的维持直射照度。输入明确网格间距、边界排除距离与不透明竖直房间墙体假设，记录旋转角；凹房间遮挡经过独立光线追踪对照。每个房间还须明确 min_uniformity 和 max_avg_lux，选择同时满足平均目标、Emin/Eavg、过亮上限、功率密度和布置限制的最低安装功率候选。这里只搜索声明的有限网格，不宣称全局最优或无解等同工程不可能。

真实候选取自厂家官方原始文件。文件摘要、来源角色、输入根目录、功率和相对光度声明流明逐项绑定；设计和交付前核对，文件声明发行日期晚于设计日期时拒绝。IES 元数据不能证明产品适用性、Ra/CCT、上市时间或实际安装。可声明产品允许用途和面板/筒灯示意符号，不能把这些声明冒称专业选型审核。原始文件、型号映射、逐点CSV、计算及独立对照保留在私有审核包中，公开源码和旧发行包不携带厂家资产。

本机验收包含194项单元检查、7项真实MCP/CAD流程检查，以及独立 Radiance 6.0.2 的11组675点对照（340个解析/角度/遮挡点，335个最终设计网格点）。逐点容差为0.05 lx加预测值的1%；当前最大归一化误差小于0.01%。独立软件被明确配置为点源直射条件，验证的是相同声明模型，不是扩展发光面、反射光或UGR正确性。

三种独立构造的办公室、值班室和走廊条件完成真实产品选型、30套灯具、4回路、5张图及逐点交付。只给面板灯时走廊过亮无解，保留照度/间距/均匀度/过亮上限，加入真实低输出筒灯后才有解。医院原六个空间另作局部可行性研究：只使用设计日期前已声明发行的2023年面板灯，保留原数值要求，再明确加入直射解释、0.4均匀度和1.5倍平均上限假设；当前有限候选全部无解，没有生成替代图。该研究不能替代原客户任务书或证明医院工程不可行，原医院主成果保持不变。

直射模式当前不含反射光、日光、UGR和复杂遮挡/吊顶；仅支持LM-63-1991/1995/2002、Type C、TILT=NONE和明确支持的水平对称范围，拒绝其他类型、倾斜补偿、非单位旧镇流器因子等情况。未实现LDT；网格预算、候选搜索和大图范围有明确上限。最终图册文字/几何可读，但密集控制关系仍有线号拥挤，属于图面深化待审；不能将PDF解析、渲染或本机流程通过作为施工图图面验收。下一步先核验本地照明/医院标准全文、适用性和指标，再补反射与眩光、实际产品适用性、遮挡条件和医院建筑空间缺项。M2—M4仍未完成。脱敏证据见[光度计算验证](photometry-validation.json)。


## M2 规范依据与图面实用性增量（2026-10-20）

本轮把 GB/T 50034-2024 的普通办公室/会议室、医疗走廊表，与 GB 55015-2021 对应当前照明功率表逐页核读，并与本地标准汇编表图交叉检查。原PDF、公告页及表图像素、核读图和解释配置分别冻结摘要；不是用公告替代指标表，也不将目标LPD误用作当前强制基准。完整原文及配置保持私有，解释只覆盖三类空间；标准是否现行、项目分类及全部条文适用性仍须专业确认。源版见[大学托管照明原文](https://zcsys.ncepu.edu.cn/docs/2025-01/d5c197c2837e4892ac7d02faae298500.pdf)及[陕西市场监管局托管节能原文](https://snamr.shaanxi.gov.cn/sy/ztzl/sbgxhxfpyjhx/bzcx/gjbz/202410/P020250320618912933247.pdf)。

新增 lighting_basis 只读动作；输入显式绑定解释配置摘要、标准来源和房间标准类别。实际生效约束取更严格的任务/标准交集，设计与交付都检查来源和工作面；不修改原始任务指标，不自动上浮功率限值。未知分类、来源/版本变化、工作面及照度区间冲突均阻断。标准解释是可审计的本机转录，不是自动条文认证。

真实标准约束揭示原布局搜索漏解：5灯会议室需要在3×2网格移除一灯；地面工作面的长走廊需要搜索到单排23灯。已加入有预算的单点移除和按功率预算扩展轴数，重新逐点检查；不放宽照度、均匀度、过亮或LPD。控制图改用分组母线示意、分开开关并避让编号，仍不是施工布线。

医院六空间另作标准预检：值班室、示教室缺少足以确定标准类别的功能依据，保持两项阻断，未生成替代医院图纸。原医院走廊工作面本来就是地面0m，未发现该项输入冲突；0.75m冲突负例来自独立验证条件，不能混同原案例。其他普通办公归类也仅为明确标记的解释，不能代替客户确认。

本轮出口是源绑定标准子集和三个独立构造条件的本机CAD验证；医院整层完整性、反射/UGR、产品独立证据、医疗专项及认证人工审核仍未完成。M2—M4保持未完成。最新脱敏证据见[规范与图面验证](lighting-standards-validation.json)。下一步优先补总照度/反射与眩光计算、实际产品质量/电气参数证据及医院空间条件，再推进真实布线、增量修改和审核身份。


## M2 有限光源、反射总照度与中断处理增量（2026-10-20）
