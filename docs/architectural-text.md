# 建筑文字与项目条件保留

工程输入不能只保留“房间名称”字符串。CAD 中的数字前缀、单位、括号和兼用说明可能是独立文字对象，不能因为不单独构成房间就从需求证据中丢弃。

`inspect_architecture` 的 `expectedRooms` 可以声明原有 `labelInstancePath`，或者有序的 `labelInstancePaths`（2—20个完整实例路径），二者互斥。拼接结果必须与声明名称逐字规范化一致，每个片段只能分配给一个房间，不能同时列入 `ignoredLabels`。同一图块定义的文字被多次插入时，使用完整实例路径区分，不能只用实体 handle。

当前拼接只支持同一实例容器、同一图层、世界坐标下正向水平的单行 TEXT。嵌套 INSERT 的各级基向量逐级变换后核对文字方向；不把定义内的0旋转当作世界方向。基向量、位置或边界缺失、旋转/镜像、MTEXT、非同高程、基线不一致和较大间隔均不猜测。邻接筛选使用明确的软件阈值：字高比≤2、基线差≤较小字高的15%、高程差≤0.001mm、水平包围盒间距为较小字高的−25%至50%。这些是保守的文字组合启发式，不是建筑或排版标准。

自动输出 `sourceText.suggestedAssemblies`，但不会自动修改房间清单。采用建议时须重新提交有明确对象路径的新请求，原请求和来源记录保留。`labelBindings` 记录已核对的名称及所有片段，包括尚未找到几何的房间；房间边界是否解析与文字名称是否匹配分别记账。拼接后的联合包围盒用于标签定位，几何变化仍须经过原有边界/重叠检查。

`ignoredLabels` 只表示不作为独立空间。其原文、实例路径、排除理由和相邻片段会保存在 `retainedIgnoredText`，进入待审问题；数量、尺寸、兼用或比较符号等仅提示“可能的项目条件”。明确源建筑包被项目种子接收后，这些问题继续进入带建筑来源ID的 `missingInputs`。不会自动推定适用房间、用途、标准分类、有效阈值或新增可执行设计要求。未支持拼接的片段仍逐个保留，不以“无法拼接”作为删除理由。

单次最多复核1000个源标签，超出时阻断完整性，要求缩小明确范围；不截断后声称全量核对。既有建筑包、原图和捕获摘要绑定继续生效，未解析房间、空间重叠、未分配边界、截断与外参遗漏仍阻断整层输入；接受推断几何不能绕过不完整清单。

每次导入新增 `spatial-review.html`，将所声明建筑线、已解析空间、原始文字和问题汇总，可按空间定位并恢复全范围。页面没有外部依赖或网络请求，所有源文本转义，脚本以内容摘要限定。图内只使用声明的建筑上下文，不显示电气对照灯位/回路。任务中心显示源标签、显式拼接、保留注记和可能条件数量，下载按登记摘要校验。

本机真实CAD验证涵盖独立构造的重复名称、分离数字与尺寸注记、项目种子传递、错误名称、摘要篡改和不改变源图；不构成新客户或设计成果验收。医院同一历史建筑根块另行重新捕获，12个病房数字前缀按原对象恢复，4类潜在项目条件保留，但43个候选空间仍只有39个推断几何，4个未解析、3组重叠，整层仍阻断。兼用标签可能描述同一空间，不能靠删除别名来“修好”覆盖率。

实际浏览器验证了任务中心内容与审核页下载摘要；单独HTML的 file 协议打开被浏览器策略拒绝，未绕过。页面脚本的定位/恢复经控制器测试，但独立HTML页面的浏览器布局和交互目视验收仍未完成。最新证据见[建筑文字验证](architectural-text-validation.json)。M2—M4、独立建筑及客户输入、用途适用性和专业审核保持未完成。
