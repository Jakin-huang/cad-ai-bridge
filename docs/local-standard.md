# 本地 DWG 标准库

学校生成器可使用本地 V02 配电箱标准，而不把企业图纸加入公开源码。指定标准 DWG 为箱柜、已有图例及电力选型的主来源；主模板缺少的报警、网络、广播图例可从已完成原生审计的施工图清单补充。

```powershell
node bin/cadbridge.mjs standard "D:\CAD-work\standard.dwg" "D:\CAD-work\manifest.json"
node bin/cadbridge.mjs school
```

第二个参数是 `tests/project-integration.mjs` 使用的工程副本清单，同目录应有 `project-validation.json`。清单中包含原图哈希及审计任务位置。导入在 `artifacts/standard-profile-*` 内新建副本、原生审计 DXF、完整定义目录和版本化映射；本地配置 `cadbridge-standard.local.json` 锁定映射哈希。重新生成学校项目前会再次核对原模板、补充施工图和审计 DXF。改图或调整配置后需重新导入。

该适配器针对已核对的 V02 结构与表格句柄，不能把任意 DWG 自动理解为规范。表结构变化、来源文字不匹配、未支持实体、循环引用或未验证敷设条件都会报错。匹配表索引目前覆盖完整核对的 16–200A 行，自动选型还要求截面位于已交叉核对载流量和保护管的 2.5/4/6/10/16mm² 范围；超出范围时报错。照明 10A 支路用表中 16A 对应的保守导线规格。

生成内容包括主进线、楼层馈线、普通支路选型、各箱出线系统图、统一图例和来源 JSON。学校默认两层时共有 19 张 A2 图，包含 8 个配电箱/接口箱系统图。馈线按独立穿管暗敷 A、30℃且不成束的假设取表值。模板内部普通导线类型存在 WDZN-BYJ / WDZ-BYJ 差异，当前采用保护管选择表的明确参考 WDZN-BYJ，并把差异留在来源记录中。消防输入、厂家应急支路保护、施工环境、短路及选择性仍须审定；不会把模板中其他项目算例当成本项目的校核结果。

几何转换保留来源句柄、插入变换与图形位置。嵌套图例展平为普通 CAD 实体，实心填充三角化，曲线按输出坐标不超过 0.05mm 弦高误差离散化。保留常量线宽；文字改用本机中文 TTF，并保留字高、宽度系数及旋转。此流程不会保留动态图块行为、专有对象语义、原 SHX 字形及所有原图颜色。黑板灯使用模板壁装 LED 图形，排风机使用电动机图形，产品功能另按设备参数说明。

R3补充模板“隔离开关”定义，主来源图形由17项增为18项，施工图补充仍为6项。普通楼层进线为4P40A隔离，上级馈线C20；应急输入隔离与原厂DC输出保护分开表示，并标明AC/DC转换。厂家器件参考、逐张核对、控制线清单和待补资料均随新项目输出，见[学校项目说明](school-project.md)。

`template-provenance.json` 记录源文件哈希、选型单元格句柄、图块来源与转换边界。`circuits.csv` 增加电线型号、导体构成、保护管及来源句柄；`cad-verification.json` 核对保存后的实体、填充、线宽、字宽、设备属性、连线和视图。可运行 `node tests/standard-profile.mjs` 校核本地规则与来源复现。

本地 DWG、DXF、映射、配置和衍生图形全部处于忽略目录，不随源码包发布。学校示例打包器会阻止将含本地衍生资产的交付物打成公开示例。需要原创公开示例时显式运行：

```powershell
node bin/cadbridge.mjs school --without-standard
```

导入和生成只创建新文件，结束时校验所有原图哈希。发布或分享企业标准及衍生图纸需另行明确授权；当前流程不推送远端。
