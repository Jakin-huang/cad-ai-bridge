# 受保护种子的功能理解接入

数值约束提取之外，客户端还需要解释实际功能及其标准类别。新增 `prepare_from_seed.functionalIntake`，在本机摘要绑定的种子上只补未确认用途，避免要求模型重新输出或改变建筑、产品和现场条件。它是有证据的解释通道，不是自动认证功能/标准适用性的方法。

每个房间提交roomId，并根据任务书提交primary、secondaryUses或unresolved。primary包含use、classId、reason、evidence；secondaryUses每项另有labelId，unresolved每项包含labelId、reason、evidence。evidence每项为sourceId和逐字quote，来源必须是brief且摘要等于完整seed.brief的UTF-8字节。原句、理由及最终应用一起冻结并进入报告。无法逐字对应、有错误来源或摘要变化时拒绝，不以模糊匹配修补。当前仅支持种子内一份精确摘要的任务书，多文档/审核指令逐句引用尚待扩展。

主用途只允许补use=unknown且没有standardSpace的空位；兼用用途只允许补原sourceSpaceLabels中secondary_use的未评估标签。已知主用途、既有标准分类、已评估兼用和别名关系不能覆盖。source、几何、入口、工作面、净高、灯具、表面、姿态、电气参数及已有缺项均保留。兼用工作面继承种子，方法限定同一固定布局/工作面/表面/姿态，不具备共同条件时必须unresolved，不能暗改条件迁就算法。

解释后的分类统一为interpreted，类别必须经已绑定标准子集解析，真实功能与专业适用性仍待确认；临床/未知功能不允许猜成普通用途。unresolved持续形成阻断，即使其他约束齐全也不能发布模型或出图。冲突数值继续由requirements保留并触发现有冲突检查，功能接口不授权自行消解冲突。

保存后独立检查器重新核对原句/摘要与主、兼用字段一致性。`status.functional_intake` 核对冻结输入摘要后返回理解记录和问题，任务中心显示原句、理由与未解项。源句相符只证明可追溯；引用一段真实文字仍可能做出错误解释，不能将这些检查称为自动语义正确性认证。

项目技能调用说明见[工程需求技能参考](../skills/cadbridge-electrical/references/engineering-design.md)。真实客户端的外发数据边界与任务权限必须按实际材料确认；本轮新增验证仅使用完全构造的非私有任务，不复用医院对外传输授权。实际客户端、输入一致性、物理计算、原生CAD、图册目视和专业审查应分别记录，不能互相代替。

实际客户端首轮记录暴露了只读参数发现问题：最终解释正确仍可能经历多次无效调用，不能把约束正确当作顺畅使用通过。工程技能与工具描述现明确给出status的三字段形式和单个section；blocked表示等待补资料，不代表后台还在计算。新验证须同时检查真实理解结果、输入保护、工具参数错误数量和运行结果，原始失败记录保留。

测试还发现沿用旧任务种子时，已有待审注记可能携带上一任务的功能说明；不能默默清空或把它当成新任务的依据。新任务与旧注记冲突必须明确登记。本轮用例仍带这项既有注记，不计作干净、未见或独立项目评测；多来源版本协调及变更影响继续列为下一优先级。

复验另发现可选集合传空数组被拒绝。现secondaryUses/unresolved允许空数组，含义与没有该类条目相同；全空记录、漏评兼用或未解决功能仍阻断。这是输入表达兼容修复，不改变任何设计指标、来源验证或用途适用性要求。

任务中心的通用blocked标签现为“存在阻断，需核对”，避免把用途缺失误导为可通过恢复计算解除的问题。需要补资料、计算不通过和实际进程中断仍须按详细阶段分别处理。

图册目视核对另发现：控制方式仅进入后台模型不足以供审图。设计说明现逐房间明确就地手动、区域集中并手动或感应并可手动，控制对象与说明按房间独立配对核对，遗漏或串用模式会失败。感应器/手动旁路、安装和接线仍需专项深化，不据此新增未经条件支持的设备或宣称控制施工设计完成。

本轮实际客户端R0图册保留为历史结果；新R1补足控制说明并重新物理复核、原生保存重开及出图。使用既有revise同值修订会保守地将该要求status从documented改为interpreted；此唯一元数据变化明确记录，全部数值、理由、原句、功能及其他种子条件保持。不能把R1输入SHA说成原始客户端输入SHA；原始input-0字节继续保留。

本机最终证据见[功能理解验证](functional-intake-validation.json)。这些验证覆盖实际客户端的受保护输入及已声明的CAD/物理子集；原始失败、元数据差异、旧注记和外部验收限制单列，M2—M4保持未完成。


输入准备的 `read section=input` 返回真实输入字段目标ID，不是section=targets。draft后可用 `read section=source_coverage`（必传该draft）分页核对原文块、blockSHA256、已提交处置和literalCitationTargetIds。候选只表示当前草稿中已有supported/assumption决定的字面引文匹配该原文块，最多返回100项并给出总数/截断标记，不自动判断语义、不选择mapped/context、不补写引用或工程值。由Agent根据原文义务选择恰当目标；没有匹配时修正对应解释/引文或保留未解，不能靠猜索引、删除要求或把未知工程义务改为背景放行。沿nextOffset读齐；历史草稿仍可读但eligible及documentsCurrent可能为false。

新冻结入口默认还要求[图面文字声明与校核](drawing-presentation.md)，不能把基线占位名称和流程描述直接带入交付。采纳前读取section=presentation，对照名称、范围、spaceIds和每条说明；原有物理条件及待审级别继续保留。
