# 可选项目生成接口

此工作流保留已有的受限需求计算、原创场景创建、批量设备布置、回读核验和报告生成能力。学校场景用于验证中间层的软件调用能力，不是项目的产品定位。仓库和发行包不提供需求示例、规范依据样本、DWG/DXF、PDF 图册或其他测试交付物。

## 自备输入

调用 cadbridge school REQUIREMENTS.json，必须明确提供自己的需求文件。字段和数值范围以 [schoolRequirementsSchema](../src/school-design.mjs) 为准，包括项目标识、日期、层数、空间尺寸、照明、电气、应急条件和假设；输入先验证再启动 CAD。无需求参数时明确报错，不回退到内置测试案例。

可用 --standards-register REGISTER.json 附带自己的依据登记文件。未提供时，输出明确标记未提供项目依据，不能当作规范符合性证明。--model-only 只预检模型，--without-standard 不使用已导入的本地标准。PDF 另外需要 Python、reportlab、pypdf 和本机字体，均不作为示例资料打包。

## 输出与保护

每次运行在项目之外的任务数据目录新建独立交付目录，不覆盖输入。模型、DWG/DXF、PDF、设备与回路表、专业待审项及摘要均由本次请求生成；可从返回路径取得。保存后使用独立 CAD 回读与 DXF 校验。源图、模板和输入摘要保留，失败输出不自动认定为有效交付。

本地标准由用户提供并明确导入，见 [标准适配](local-standard.md)。不提供示例打包器或公开图纸下载。

## 工程边界

照度和压降依赖输入及显式假设。没有实际建筑、配光、供电、设备产品和短路接地数据时，不报告已满足照明质量、保护配合、消防闭环或施工审查。正式用途应由专业人员补齐资料并审定。

专项回归测试可读取维护者放在项目外的私有需求文件；不随源码和发行包提供这些文件。[外部测试数据约定](asset-separation.md)
