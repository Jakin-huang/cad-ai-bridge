# 受阻任务的来源修订与恢复

本轮收口同一任务“条件冲突→新来源→重新审阅→设计/检查→CAD/审核包→共享来源发布”的本机闭环，没有新建任务规避原阻断，也没有改写受阻版本。

接口增加只读的 project_documents `editable_presentation` 动作，参数为原 task 和当前 set。intake 的 inspect_presentation、read_presentation_revision 的 presentation 页也提供 editablePresentation。该字段只含 title/scope/notes、spaceIds 和 reviewed，去除存储元数据及派生引文摘要，供 parameters.presentation 编辑；没有既有项目文字时返回 null。模板统一 reviewed=false，不能直接当作已审阅或专业许可。调用者仍须核对新来源、调整适用说明，再显式 reviewed=true；完整响应包装继续被严格拒绝。原目标值、摘要、草稿和输入不因读取而改变。

恢复试验接续已封存的同一办公测试任务 R3。先将448份原任务数据与上一封存清单逐项匹配，并保存完整前镜像，再添加合成协调原文的新版本。新原文明确将固定柜宽度50000mm修订为1200mm，固定坐标、朝向、净空、等级及其他物品/房间条件保持；这是新的声明输入，不是求解器自行改值，也不证明真实签发权限。

真实 Agent 使用编辑模板，重新判断项目说明，完成新字段和原文覆盖审阅与绑定，沿原任务推进到 R4，生成新的 DWG、七张审核 PDF 及共享空间来源。固定柜位置和其他工程条件保持，五项专业/现场待审边界保留。新共享来源 current=true，旧来源仍为历史；未声称已验证下游照明/机电消费者的实际采用和重算。

R4最终设计状态校核通过，七页经严格解析、图幅/像素、原文说明、物品表及变更JSON/CSV独立核对，并逐页查看。变更表追溯三个物品输入修订、四项字段变化，其中包括没有生成设计的R3受阻条件；这不是对每个历史版本的设计验收。旧原文、输入、模型、图纸、失败调用及R3状态均保留，七个当前生命周期视图通过前镜像衔接，不声称所有原路径未变。

客户端仍发生一次 DOCUMENT_SOURCE_TARGET_CITATION_REQUIRED：把未被目标引文覆盖的原文段映射到了该目标。Agent自行修正后完成，本轮没有响应包装误用，但全过程零错误门槛仍不通过，不能由一个样例推断模型替换后的稳定性。

本轮开发和声明条件下的恢复子集本机验证完成；它是已知合成矩形案例的接续，不是独立委托语义验收、完整医院项目或施工签审。详见[验证记录](asset-recovery-validation.json)。下一步转向独立原始委托的条件义务、说明适用性和跨专业依赖验证，避免继续围绕同一案例扩散。冻结 v2.0 和现有发行包不重打；完整复杂工程目标及外部用户、新机器、专业验收继续单列。
