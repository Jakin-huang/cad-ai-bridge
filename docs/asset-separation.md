# 源码、用户数据与本地验证资料

公开项目仅提供实现代码、工具契约、安装入口、Skill、文档、测试代码和必要的发布元数据。不提供预置图纸、示例需求/依据文件、测试预览、私有模板、工程副本、模型交付、原始报告或历史发行测试目录。

## 存储位置

用户选择的图纸目录继续作为输入范围。新任务的快照、DWG/DXF 和诊断默认存放在 Windows 用户本地应用数据目录的 CADBridge/data/runs 中；安装和升级自动沿用已配置的数据位置，无需用户填写环境变量。支持 Linux 的无 CAD 测试使用对应用户数据目录。

维护者通过 CADBRIDGE_TEST_HOME 指定项目外的验证目录，未设置时使用用户数据目录下的 validation。目录中可分别保存 artifacts、runs、dist 和私有输入；源码目录内不再生成这些目录。CADBRIDGE_DATA_HOME 可指定项目外任务数据位置。程序拒绝将数据目录设置为源码目录或它的子目录。

本机迁移清单和原始资料存放在项目外；cadbridge-validation.local.json 仅记录维护者的外部目录和旧报告地址映射，已忽略且不打包。旧报告字节不修改；读取时可映射已经迁出的地址。旧会话文件卡片的原地址可能失效，应按新位置或任务查询结果打开。

## 测试与发布

单元测试代码可保留小型程序化契约输入，但不附带图纸或案例数据文件。涉及学校需求的专项测试通过 CADBRIDGE_SCHOOL_REQUIREMENTS 读取维护者自备 JSON，缺少数据时明确跳过；不能把跳过当作专项通过。

真实 CAD 测试按请求即时创建临时验证图，全部产物留在项目外，不作为发布附件。公开包采用白名单，并拒绝示例目录、图纸格式和测试预览资产。开发者包与用户包均执行此约束。

发行 ZIP、校验文件和解压验收暂存也生成在外部验证目录。GitHub 发布上传新的用户 ZIP、同名校验文件和发布说明；不上传本机资料目录、原图、历史测试包或私有配置。Git 历史是否已清除旧示例，应在推送前单独核对。
