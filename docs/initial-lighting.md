# 从冻结输入启动总照度设计

`solve_lighting` 从 `prepare` 保存的输入及已核对来源开始，不要求已有模型、直射可行方案或先前的实测复核。它也可以接在默认 `design` 的有界直射搜索失败之后。直射搜索失败不等于总照度设计无解，失败记录会保留在首次求解的历史中。

## 输入与动作

请求绑定 `jobId`、`expectedRevision`、`expectedInputSHA256` 和唯一 `requestId`，候选/时间预算与既有反馈求解相同。输入必须声明点源诊断、封闭漫反射条件、产品IES、全部房间目标及来源；请求UGR时还须明确姿态、参考表面、方法解释摘要和房间标准类别。未知分类、变更的来源、缺失条件会阻断，并保存预检失败记录，不为启动设计补造标准或装修事实。

`design` 保留原有直射行为。首次求解不自动覆盖已经存在的模型：已有模型应使用 `optimize_lighting` 与 `adopt_lighting`，需求变化应使用 `revise`。新入口不接受模型端任意灯位、执行路径或“跳过照度约束”选项。

## 求解与发布

初始排序仅用源目录和有界几何生成的直射诊断。报告明确 `measuredBaselinePresent:false`，没有虚构的原模型、基线功率、反射增益或初始总照度预测。每个实际候选都重新计算有限发光面、反射总照度以及全部已请求UGR；失败后可以用这个已冻结候选的真实输出重新排序，记录反馈来自哪个模型和报告，不能改称先前已验收基线。

已知的回路容量或控制位置构造失败只拒绝该候选并保留原因，其他内部错误仍明确中断。空候选池、采样/时间预算耗尽、数值不稳定及范围不支持都不能宣布全局无解。搜索最多检查64个不同方案、每轮beam32，昂贵复核仍受1—6个候选及2—60分钟预算约束；全流程预算从UGR方法读取及候选预检之前开始，房间间异步让出，计算子进程按剩余预算和单次上限停止并保留证据；操作系统调度及收尾使它不是硬实时截止。

只有所有声明房间同时通过原要求与标准交集、总照度、均匀度、稳定性及已请求UGR后，才在当前输入修订发布第一个模型。发布前再次核对原输入、标准来源、产品字节、模型与原始计算证据。发布不修改输入摘要，不生成假的旧修订，也不建立专业签审。`deliver` 随后再次验证所选模型、输入修订、完整质量证据和决策摘要，才允许原生CAD创建、保存重开与出图。

报告、源输入快照、来源解释、每个完整候选及原始场景/计算数据保存在本机。初始搜索报告没有 `baseline.json`。审核包不要求不存在的 `model--1.json`，而是保留真实输入与来源。原始设计模型中的布局表保留直射诊断。新交付会在不改动模型/复核报告的前提下建立独立出图投影：E05展示重新核对的总平均照度、U0、已请求参考UGR及指标，绑定模型与报告摘要。未请求UGR明确标出；实际条件和专业适用性仍待审。原始CSV保持原计算口径，不能混写。

## 中断与恢复边界

`recover_initial_lighting` 按输入摘要和修订恢复。只有核实记录的计算进程停止、原输入未变、没有已发布模型或CAD，且仍处于首次计算阶段时，才归档原租约并回到准备状态。部分候选及其目录保留，新的请求使用新目录；旧请求不自动重放未完成计算。访问权限错误不是文件不存在。

一旦已经开始发布模型文件，或根目录出现无法核对的模型，恢复会明确报告 `LIGHTING_PUBLICATION_UNCONFIRMED` 并保留文件。这一版不声称已解决所有发布崩溃或CAD状态不明的自动调和；不能以恢复计算来覆盖不明成果。现有设计的复核/优化仍使用 `recover_lighting`。

## 验收与限制

验收需要证明：同一输入的直射搜索确实未形成模型；首次求解没有伪造基线；实际计算后才发布模型；每个声明房间均满足同一组原指标；源输入不变；来源或证据变化阻止发布/出图；空池和未知分类不生成模型；真实CAD保存重开及逐页检查完成。控制流程模拟测试与真实MCP/Radiance/CAD、独立数值核对分别记账。

候选族、封闭房间、产品发光面近似、参考UGR及计算预算仍受[反馈求解](lighting-feedback.md)和[UGR方法](ugr-method.md)的范围限制。当前源码总预算为100房间、1000灯具、10000网格点；每个完整房间仍不得超过100灯具/1000点，分区只做账，不截断网格。默认并发1，显式并发上限4。代码上限不是实测能力：已知12房间/双并发实测的当前状态见[完整范围验证](whole-floor-quality-validation.json)，不能外推为100房间性能、独立建筑权威性或客户任务理解。坐姿空白、真实产品与额定电气参数协调、医疗专项、外部用户、新机器和认证专业审核仍待完成；M2—M4不因此通过。


同一次不变输入、独立封闭房间的研究内，经过固定设置/输入/网格及原始工件再审的局部失败会按房间与布局摘要排除；改变其他房间不使该失败失效。排除记录绑定来源模型/质量报告及失败检查，不跨项目或研究缓存，也不宣布全局无解。到最后一个物理候选预算就停止，不再为无剩余预算的整层重新排序；已完成失败结果不会因反馈阶段超时而被改记为未完成光度计算。该修复有真实失败报告的决策重放证据，完整12房间最终源码物理复验仍未完成。
