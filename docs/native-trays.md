# 天正 V8 原生桥架

通过现有cad_edit提供三种受约束操作，仍使用现有MCP连接器、全局Skill和中文开始入口。AI从查询结果传递句柄、文件摘要、文档身份、版本和请求UUID，普通用户不操作这些内部字段。用户只需已有正常授权的AutoCAD 2022与天正电气V8。

| 操作 | 范围 |
| --- | --- |
| create_native_tray | fromPoint、toPoint为毫米WCS平面坐标，width、height为正值尺寸；创建真实TCH_CABLETRY / TDbECabletry独立直线槽式桥架 |
| set_native_tray_size | 选定handle，修改width、height，同时匹配本机目录库中的型号 |
| add_native_tray_label | 选定桥架handle，指定外侧引出拐点position与不同的落点landingPoint；创建真实TCH_CABLEDIM / TDbCableDim并核对桥架关联 |

尺寸必须在本机安装的槽式桥架目录中唯一匹配。目录只读，不随项目分发；不执行目录中的SQL文本。缺失、损坏或未收录的尺寸明确报错，避免“几何改了、型号仍旧”的结果。标注沿用当前天正的文字样式、比例和显示字段，不表示已定义完整厂家标注标准。

本轮桥架两端为无向几何端点，不定义电气流向或高差。若第二点为WCS原点，桥梁内部交换两端以避开V8输入终止问题；实际存储顺序以保存后的查询为准，几何位置保持相同，调用者无需处理此差异。

原生批次不能混入普通编辑或electrical_apply操作，host省略时自动选择tangent，显式core会被拒绝。新建后先保存、查询真实句柄，再添加标注。查询原生对象需host=tangent，types可选TCH_CABLETRY或TCH_CABLEDIM。桥架返回实际曲线长度、端点及原生宽高/样式/型号；标注返回原生类、关联句柄和文字高度。可据桥架查询结果按型号和尺寸汇总根层几何长度，不能宣称与厂家全套统计窗口等价。

专有标注不通过COM或Explode提供完整文字，因此文字核对使用cad_export的真实CAD图像。保存后在新宿主中查询关联，并在尺寸/型号变化后检查真实标注图像；源图上的普通文字不作为原生关联证据。天正完整桥架模块与对象解释器有不同的交互能力，宿主优先加载所选天正的完整模块，并在写入前验证实际加载路径。

修改仍在输入快照内进行。操作前检查直线、平面、槽式系列及与相邻原生桥架的间隔，接触、相交或净距不大于1毫米会被拒绝；未知曲线/连接件按包围框保守排除。原生UNDO组覆盖整个批次，失败时核对原生属性、关联和模型根实体集合；回滚无法确认则拒绝发布输出。新增其他根实体、删除原对象或改变既有桥架时，不接受为“独立桥架成功”。桥架及既有标注图层锁不会被解除。完成标记绑定请求身份与响应摘要，确认文件写入完成后回收本任务宿主及子进程；不关闭用户另行打开的CAD图纸。

当前范围不包含连接弯头、三通、交叉件、梯式/大跨距桥架、任意厂家命令、负荷/容量计算、自动绕障和全套厂家统计一致性。未知关联和代理对象仍不开放通用写入；其他CAD或天正版本需独立适配验收。

维护者运行node tests/native-tangent.mjs验证真实MCP及CAD流程。测试在项目外生成临时图纸和报告；仓库、历史和发行包不携带图纸、目录库、厂家模块、REA原始字节或预览图。REA用于本机命令和类型库的有界分析；执行契约以真实宿主的保存重开、关联、出图和回滚结果为准。
