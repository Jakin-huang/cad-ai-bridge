# 复核驱动的照明选型与布局

本功能从已有、源文件绑定的普通照明模型及其实际复核记录继续求解。它可以修正总照度过亮、直射保守选型或部分眩光失败，保留原需求、标准类别、产品参数、工作面、姿态和表面假设。它不读取医院最终对照，也不自动修改客户指标来取得“通过”。

## 工作流

1. `prepare` / `design` 形成直射选型基线；`assess_lighting` 留下冻结模型的有限光源总照度及已请求UGR记录。即使基线复核失败，也可以作为有来源的设计反馈。
2. `optimize_lighting` 绑定基线 `modelSHA256` 和唯一 `requestId`，在输入已有目录内生成候选。按每产品有界几何池轮流计算直射诊断，避免一个产品的众多移除变体耗尽全部采样预算。
3. 基线实测总照度/点源直射平均值之比仅用于候选排序；它不用于缩放IES、维护系数或最终物理计算。候选需要重新计算有限发光面、反射光和全部已请求UGR。
4. 找到可行候选后，原修订仍保持原样。`adopt_lighting` 绑定原模型和优化报告摘要，重新核对标准、产品、候选模型、原始计算数据和所有门禁，才保存新设计修订。输入摘要保持相同，旧模型与复核保留，旧审核失效。
5. `deliver` 再次检查新模型、已采纳决策证据与完整复核，随后才进入原生CAD保存重开和出图。候选尚未采纳、数据变化或复核失败均不能交付。

`status` 的 `lighting_optimization` 分节返回有界候选、预测排序、实际结果、失败原因和保留证据。任务中心显示候选预算、当前计算档位、前后功率及修订，并可查看原始优化记录。AI客户端可自动串联优化、采纳和出图；采纳动作不构成专业签审。

## 计算与验收口径

默认 `design` 仍保留直射选型行为。优化候选使用 `finite_diffuse_required` 设计口径：直射平均照度和均匀度可以低于总照度目标，它们仍按原始IES重新计算并单独列示。模型检查明确把总照度验收交给强制的独立复核门禁，而非将“直射未达标”改成数值达标。新方案只有在中/精两档总平均值、均匀度、数值稳定性及已请求UGR全部满足原条件时，才可采纳。

模型检查中的 `FROZEN_TOTAL_LIGHT_REQUIRED` 记录的是该模型依赖的外部复核；是否已经满足，应读取对应模型摘要的完整质量报告。模型检查项数不等于工程合规分数。绘图表格继续保留直射计算口径，总照度与UGR见另附报告及CSV，不能把两种数值混写。

搜索在首个完整通过的候选处停止。`feasible_found` 证明在当前声明模型下找到了可行方案，不证明全局最优。`budget_exhausted`、`bounded_pool_exhausted`、表格空白和不支持条件都不能写成工程无解；未完整计算的候选不判定合格或不合格。

当前边界为每产品最多16个点源诊断布局、每房间最多24个排序候选、整项目beam32、每房间最多200个产品/布局点源组合及既有逐点工作量上限。目录覆盖在房间预筛阶段记账，beam不保证穷举跨房间组合。昂贵完整复核预算默认4个候选，可选1—6；时间预算默认20分钟，可选2—60分钟，在新的计算档位开始前检查。已经运行的单个原生计算受原有超时约束，时间预算不是强杀进程的精确截止。每次实际光照复核仍限制10个房间、100套灯具和1000个网格点；超出候选记为范围不支持，不能冒充不可行性证明。

## 证据、恢复与修订

原始基线报告和其计算场景/输出会复制进优化证据，按摘要核验。每个实际复核的候选保存冻结模型、模型检查、场景、命令、逐点CSV、UGR观察位置与报告；失败与中断记录保留。优化研究和已采纳模型的决策证明分别保存，之后再次搜索失败也不能丢失当前模型的有效采纳依据。需求修改则使旧候选、质量和采纳状态失效，历史记录保留它们的来源。

`recover_lighting` 只在证实记录的计算进程停止、原模型/输入未变且阶段相符时归档中断状态。优化中断时保留原方案已有复核，部分候选不自动采纳。恢复不能证明全部子进程状态，也不能重放CAD。新修订文件若已存在但与候选冲突，则保留文件并报告状态待核对，不覆盖不明成果。

## 尚未达到的能力

反馈入口仍要求已有复核基线；现已新增不依赖直射可行方案的输入首次求解入口，见[首次总照度设计](initial-lighting.md)。初始候选没有虚构的测量基线或反射增益，完整计算后才可发布模型。候选族仍为现有轴向网格及有界单灯移除，不含任意形状最优化、连续灯位/旋转搜索、实际吊顶协调或成本/可采购性求解。排序传递增益是启发式，实际差异由重新计算发现；没有全局最优或严格数值误差界。

参考房间UGR仍受[UGR方法](ugr-method.md)的姿态、位置表和均匀发光面模型限制；坐姿表格空白不能以站姿结果替代。厂家标称值、目录与IES电气参数差异、真实产品亮度、建筑/装修权威性及专业适用性仍需独立证据。合成开发用例不是未见项目验收，医院整层、医疗专项、外部用户、新机器和专业审核仍未完成，M2—M4保持未完成。

点诊断候选池现按灯数分层采样，防止低灯数的单点移除变体占满16个名额；保留原预算、源几何与全量物理复核。覆盖数量进入研究记录，仍不声称穷举或全局最优。见[共同用途与候选覆盖](shared-use-lighting.md)。
