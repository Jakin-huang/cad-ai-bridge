# 安装与排障

先调用 MCP 的 `cad_doctor` 或运行 `npm run doctor`。即使 CAD、工作区或配置不可用，MCP 仍能连接并提供诊断；Node 或 MCP 库自身不可用时需要先运行 setup。缺少插件时运行 setup；选择多个 AutoCAD 安装时明确给出 `--cad-root`。本版只验收 AutoCAD 2022，其他年份需要对应 API 和独立验收，不能直接复制 DLL 宣称兼容。

`setup` 优先复用目标版本、DLL 摘要和源码均匹配的插件；`--skip-build` 也要求通过校验，不能跳过损坏插件。开发者修改源码后可用 `--rebuild`。工作目录不存在时自动创建；路径是文件、不可访问或配置格式损坏时返回对应错误。

任务超时、断连或写入错误时，先调用 `cad_get_job`。用 jobId 获取结果；未收到 jobId 时用原 requestId 找到对应尝试，再逐个查询。`status: unconfirmed` 表示缺少最终记录，仍可能在执行或存在未确认结果，不自动重放。`outcome: saved` 时检查现有 drawing；DXF 导出或宿主清理失败不代表 DWG 未保存。工具保留错误阶段、任务目录和输出摘要，分页与恢复查询均不启动 CAD。

环境检测缓存仅在同一 MCP 进程内保留至多 30 秒；配置、关键环境变量、宿主、插件和检测脚本变化会使缓存失效，`cad_doctor` 的 `refresh: true` 强制检测。图纸摘要、文档身份、版本、事务和原图保护不使用该缓存。

## 首次启动

正常启动本机 CAD 一次并完成首次使用流程。登录与授权界面由用户操作。天正“日积月累”属于普通使用提示，会在本项目独立任务期间临时抑制并恢复；该操作不改变授权数据。

图形宿主需要 Windows 交互式桌面，运行时会显示独立测试会话。CoreConsole 适合普通图块与 XData 的快速读写，不能直接替代完整天正 GUI 初始化。

## 加载失败

本项目 CLR4 DLL 使用 NETLOAD，天正原生 ARX 使用原生加载方式。工具临时信任精确插件目录，并保留安全加载原值；完整天正内核通过启动预载处理，不使用安全警告按钮作为自动化接口。

天正电气与天正对象解释器可能都提供 `tch_kernal.arx`，但文件并不相同。若打开含代理图形的 DWG 时出现另一目录的未签名提示，检查 native-status 和启动参数；不要将整个安装盘或工作区加入受信目录。

宿主通过 `/ld` 明确选择完整天正内核；`/b` 必须位于参数末尾。原生参数参见 [AutoCAD 2022 官方参考](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-Core/files/GUID-8E54B6EC-5B52-4F62-B7FC-0D4E1EDF093A.htm)。

## 超时与恢复

错误中会给出 jobRoot。查看 host.json、response.json、startup-preferences.json、cleanup.json 和临时 stage。源图始终保留；输入副本可能被 CAD 初始化更新，不能把该副本当作原图。

`TIMEOUT_STATE_UNKNOWN` 不代表没有写入。不要自动重复请求。配置冲突时，工具保留外部变更；先退出不相关的测试会话，再检查需要恢复的项目自有值。

本机曾设置 acad.exe 的 RUNASADMIN 兼容标记。宿主为自己的独立进程请求普通用户权限并使用显式 CreateProcess，避免 ShellExecute 的提权等待；不修改该兼容标记。启动时记录 PID、时间和路径，超时只清理自己拥有的进程。

## 工程图的额外对象与字体

真实图可能在启动脚本之前按需加载对象解释器中的 tch_pipebase 等模块。宿主只对选定安装及相邻已安装 V8 对象解释器的精确 sys24x64 目录临时受信，任务后恢复；不关闭 SECURELOAD。不要把完整 ARX 清单全部强行预载，tch_public 等旧模块依赖正常的天正启动顺序，可能在早期初始化中抛出原生异常。

缺少 SHX 时，先取得原设计使用的字体/形文件。本版先用自建空白 DWG 初始化，再通过会话级文档 API 打开快照，避免启动时字体选择阻塞；原有字体记录保留。没有原字体时不能承诺正式出图外观，日志中的替换和缺字需要单独复核。不会下载来历不明字体或用替代文件冒充原文件。

原始审计成功、DXF 导出报 eNullObjectId 时，保留该失败记录，使用 cad_repair_copy 在快照上运行 AUDIT 并另存。AUDIT 可能删除无法修复的对象；核对日志、修复前读取结果和修复后 DXF，不能把修复成功当成所有内容完全无损。原图 SHA-256 必须保持不变。

大图请求 detail:full 后收到 responseTruncated，说明完整记录保留在任务目录但传输改为有界摘要；使用 cad_read_result 按 nextOffset 继续。分页同时限制条数和字节数，避免触发 MCP 传输容量导致断连。

## 数据统计不同

先看 coverage 和 unitsSource。根层 INSERT 数不等于设备数；背景建筑块不应计入设备。Undefined 单位默认只报告图面长度。原生对象未解释时会报告代理，嵌套块与外参当前不展开。

长度是图面几何长度，不是含标高、余量和根数的采购电缆量。回路字段是读取到的线路信息，不自动等同于完整电气连接拓扑。
