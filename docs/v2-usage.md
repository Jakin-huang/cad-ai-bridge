# v2.0 用户包：使用与验证边界

本页适用于冻结的 v2.0 用户包。源码中的工程设计增量见[项目首页](../README.md)，发行验收记录见[v2验证摘要](v2-validation.json)。

## 选择入口

| 任务 | 入口 |
| --- | --- |
| 单图查询、编辑、统计和出图 | AI连接器中的 `cad_workflow` |
| 多张图批处理 | `cad_project`，或双击 `任务中心.cmd` |
| 完整捕获上的工程检查和计量 | `cad_scan_drawing` 后使用 `cad_analyze` |
| 当前视图或选择集（实验性） | `cad_session` |

参数及操作顺序见[项目指南](../skills/cadbridge-electrical/references/project-analysis.md)。任务中心只监听本机，提供常用任务、进度、验证结果和交付下载；细化任务使用AI客户端。读不到图纸时检查已配置工作目录，无需把图纸复制到源码目录。

## 文件与恢复

- 多图项目先冻结全部源图，再逐图另存结果，源图不覆写。
- 关闭任务中心页面不取消任务；取消在当前图完成后停止后续图。
- 保存后即使后续验证失败，也保留DWG。断连或状态不明时先查原任务，不重复执行修改。
- `reexport`只重导失败的输出，保留原执行与后续交付记录。

## 如何看结果

`ok`只表示执行结果。源图身份、保存、CAD重开、几何、非目标对象保护、渲染和人工视觉复核分别报告；部分或未知不能算完整通过。

几何和非目标保护覆盖声明的二维对象及DXF记录，未覆盖的操作在pending中列出；不证明全部厂商对象或数据库语义不变。PDF/PNG生成成功也不证明所有字体、图面规范和打印驱动都已验收。

计量保留范围、单位、系数、损耗、进位及逐实例来源。图面数量不自动等于安装净量；未知单位、截断或读取错误不得报完整物理总量，标签分组不等于电气连通或实际回路。
