让 AI 使用你已有的 CAD

解压 → 接入 → 在 WorkBuddy 中说出任务

Windows 用户预览 · 无需了解 GitHub

开始前：电脑上已有正常可用的 AutoCAD 2022 和 WorkBuddy，天正电气 V8 可选。桥梁自带所需运行环境，无需管理员、开发工具或额外 API 密钥。

1解压后，双击中文入口

把完整用户包解压到自己的固定文件夹，双击 开始使用.exe。选好图纸文件夹，点“接入 WorkBuddy”，等待结果。

不需要另开软件注册账号；请保留整个解压目录。后续会沿用已选目录。

2在 WorkBuddy 完成首次信任

进入“专家·技能·连接器 → 连接器 → 右上角自定义连接器”，找到 cad-ai-bridge，核对本机路径后点“信任”，等待已连接、工具加载。

本机准备成功不等于客户端已连接。“1 启用”也不代表已完成信任。上图为位置示意。

3新建任务，说出需求

在任务输入框的“+ → 连接器”中确认已选用本项目，再粘贴下面的示例。全局 Skill 会提供操作指引，不需另外手动安装。

AI 返回 DWG/DXF 文件入口；需要时在本机 CAD 中手动打开。文件卡片不等于内嵌预览。

第一次可直接试这句话　也可在中文入口中点击“复制第一条任务”

看到失败提示怎么办？

按窗口中的中文建议处理后重新接入。若仍失败，点“查看日志”，把错误信息交给分享者；无需自行修改配置或运行命令。日志可能含本机路径，分享前请去除个人和工程信息。

更换目录、升级与恢复

更换图纸目录：重开中文入口，选目录后重新接入。升级：保留旧安装目录，在新目录接入。需回退时先结束任务并退出 WorkBuddy，再运行 restore-workbuddy.cmd。

CAD AI Bridge 负责连接已有软件和 AI。接入不会修改原图纸；绘图能力仍受当前适配范围约束。本版未完成干净 Windows、独立标准账户和浏览器下载安全提示流程验收，其他 CAD 版本与客户端需另行验证。详细说明
