# Existing drawing editing

Use connected cad_query_entities, cad_edit and cad_export. Do not ask the user for internal handles, UUIDs, hashes, job folders or revisions.

1. Query the named drawing with explicit type/layer/region/text/attribute filters. A region means a WCS XY bounding-box filter, not precise shape intersection. Ask only when multiple candidates make the requested target ambiguous. If no documentId is returned, prepare a copy with cad_prepare_project after confirming that the drawing already declares mm, then query that copy. Undefined units require the user's decision.
2. Bind selected handles to that query's inputSha256 and drawing. Carry documentId/revision into one cad_edit batch with a new UUID. Do not reuse handles from another drawing or an older file digest. If truncated, refine the filter or page retained entities; paging does not fetch entities omitted by the query's limit.
3. Ordinary edits include move/copy/rotate/scale/mirror/rectangular array, erase, text/attribute/layer changes, primitive insertion, ordinary local block insertion, curve offset, straight-LINE trim/extend, dimensions, named views and a new layout. Read the actual tool schema. Mirror defaults to a copy. Trim explicitly keeps the segment between fromPoint and toPoint; extend_line requires an outward point. Dimensions use fromPoint/toPoint and radians. Never turn broad natural language into erase-all or force-unlock.
4. Use move_devices for managed devices so their route anchors stay connected; moving both endpoints translates the entire route, moving one endpoint leaves internal bends in place. Use update_route for known managed route geometry, circuit/specification and explicit endpoints. add_route_label creates a bridge-associated ordinary text label. DEVICE_ID uses number_devices. Do not generic-copy/delete/mirror managed objects or edit unknown vendor data.
5. Inspect the saved output in a fresh CAD call. Verify counts, positions, requested property changes, dimensions and connectivity. Use cad_export format=png for actual CAD visual feedback, optionally with a Model region; inspect returned images when supported. cad_export format=pdf can plot Model or a named layout. Return exact file paths and the checked changes. Neither image export nor a file card proves a client supports DWG preview.
6. Failure aborts the batch. After timeout/disconnect, recover with cad_get_job using the same requestId before retrying. A saved DWG can survive DXF/export failure. Never overwrite original files or retry a mutation just to obtain a preview.

Dynamic blocks, xrefs, nested entity edits, proxies, unknown XData/associations and locked layers are outside generic write scope. Managed route updates are not vendor topology reconstruction. Native Tangent trays and their labels use the separate [native workflow](native-tray-workflow.md). Unrestricted commands, connected tray fittings and automatic obstacle avoidance remain unavailable.
