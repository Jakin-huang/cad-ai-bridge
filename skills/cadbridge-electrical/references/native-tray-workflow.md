# Native Tangent V8 trays

Use connected cad_edit, cad_query_entities and cad_export. Read their actual schemas: older servers may not support native operation types. Do not ask users to run commands, install a second connector, find handles or load ARX modules. The configured bridge owns host startup and module selection.

The supported family is a straight, independent, planar channel-type (槽式) tray in the installed Tangent V8 catalog. Use create_native_tray with explicit mm fromPoint/toPoint and width/height. Use set_native_tray_size with a selected native tray handle and dimensions. The bridge resolves its model from the installed catalog; NATIVE_SIZE_NOT_CATALOGUED means that exact size is unavailable, not a reason to invent a model or silently choose another size. Other families, intersections, bends, tees, connected fittings and vendor-wide statistics are outside this workflow.

These planar tray endpoints are undirected. The bridge internally swaps an origin-ending pair to work around the V8 jig's termination behavior; use the saved query's actual endpoint order. Do not ask the user to reorder coordinates or claim the pair defines electrical flow or elevation changes.

Query existing targets with host: tangent and types: [TCH_CABLETRY]. Bind handles, documentId/revision and inputSha256 to this exact drawing. Native operations belong in a separate cad_edit batch; do not mix them with ordinary edits. Carry normal source protection and UUID rules from the editing workflow.

To annotate a saved native tray, use add_native_tray_label with its handle, a position outside the tray width and a distinct landingPoint for the horizontal/text landing. Choose sensible positions from the drawing geometry. The bridge finds the native midpoint itself and performs the complete native placement. Create trays first, then query their saved handles before adding labels. Query labels using host: tangent and types: [TCH_CABLEDIM]; inspect nativeClass, targetHandles and textHeight. Verify the actual rendered model text with cad_export PNG, including after requested size changes. This native class does not expose its complete rendered text through COM or Explode; do not claim a text query proved it. An ordinary TEXT label is not an acceptable substitute for a proprietary associated label.

After any native batch, inspect the new DWG in a fresh CAD call and use actual PNG feedback when available. Return exact DWG/DXF paths through the client's file presentation capability. If a batch fails or completion is uncertain, use cad_get_job before any retry. Do not repeat writes to obtain a preview. Explain unsupported assembly or catalog errors with the specific failed condition; preserve original drawings and any already saved output.
